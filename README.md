# Con11's AI Skills

openode 平台的 AI Skills 集合，用于扩展 AI 助手的专业能力。

## Skills 列表

| Skill | 描述 |
|---|---|
| **mcp-builder** | MCP (Model Context Protocol) 服务端构建指南，支持 Python (FastMCP) 和 Node/TypeScript (MCP SDK) |
| **skill-creator** | 技能的创建、编辑、评测和优化工具，支持基准测试和描述优化 |
| **storyboard-pipeline** | 文案一键生成分镜 Excel 表格，自动分词分镜并导出带颜色标注的 Excel 文件 |
| **video-metadata** | 根据 SRT 字幕和达芬奇工程生成视频简介、分段章节、BGM 列表 |
| **yutto-downloader** | 使用 yutto 下载哔哩哔哩视频，支持番剧、课程、弹幕、字幕、音频提取等 |

## 目录结构

```
skills/                         # 各技能定义
  mcp-builder/                  # MCP 构建指南
  skill-creator/                # 技能创建与评测
  storyboard-pipeline/          # 文案转分镜
  video-metadata/               # 视频元数据生成
  yutto-downloader/             # B站视频下载
  yutto-downloader-workspace/   # yutto-downloader 开发工作区
```

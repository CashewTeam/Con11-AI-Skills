按钮（Button）是一种命令组件，可发起一个即时操作。

## **Button 的常见分类**

* 提交类：如 “提交”、“确认”、“保存”，用于执行最终操作并将数据传递给系统。

* 操作类：如 “选择”、“编辑”、“复制”，用于对内容执行具体处理。

* 导航类：如 “返回”、“下一步”、“查看详情”，用于页面或流程间的跳转。

* 功能类：如 “刷新”、“搜索”、“打印”，触发工具性或辅助性功能。
* 交互反馈类：如 “关闭弹窗”、“取消”，用于中断或放弃当前操作。

### 角色
不同角色的按钮具有不同的语义，通常在视图中会保留一至两个突出显示的按钮。向用户提供过多突出的按钮会加重其认知负担，导致用户需要花费更多时间权衡各项选项后才能做出选择，而采用填充效果或颜色鲜明的按钮通常更具吸引力，能够协助用户快速识别最有可能想要执行的操作。
分为五种角色按钮：

1. 主要按钮：即默认按钮，为用户最可能选择的按钮。通常，在一个操作区域内仅允许存在一个主要按钮，例如 “完成”。
2. 辅助按钮：在界面上，使用辅助按钮进行中等强度的操作。

3. 可通行按钮：用于特定场景以实现相应功能的按钮，如下图，绿色 **开始玩** 按钮。

4. 其他按钮：常设置于图片或文字之上，且背景带有模糊效果。

5. 无边框按钮：无边框按钮没有背景。适用于不常用的操作，以突出其他操作。

以及 **Danger** 危险状态按钮：删除、移动、修改权限等这类具有一定风险性的操作。此类操作可能会对系统数据、文件结构或者软件功能等造成不可逆的影响，进而导致数据丢失、系统故障或者权限混乱等严重后果。为了最大程度地降低因误操作而引发的潜在风险，在执行这类危险操作时，一般都需要进行二次确认。

## 交互行为
按钮分为四种交互状态：

* Normal 默认状态：按钮在无任何操作且未出现特殊情况时的默认显示状态。
* Hover 悬停状态：当通当手势等其他方式扫过按钮时，按钮进入悬停状态，图标背景颜色会改变，以向用户提示该元素可点击。
* Pressed 点击状态：当按下按钮时，会触发点击事件，同时按钮的背景颜色会发生改变。
* Disable 不可用状态：由于某些原因，按钮当前处于用户无法操作的状态，呈现置灰显示。此时按钮会以变灰来直观地向用户表明它当前不能被使用，以避免用户在不适当的时候误触发该按钮对应的功能。

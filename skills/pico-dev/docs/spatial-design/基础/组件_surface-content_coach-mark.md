Coach Mark 常用于帮助用户理解新的功能或引导用户操作，通常不会阻断用户交互，页面内未被遮挡的 UI 元素可以正常响应。同一时间建议只显示一个 Coach Mark，保证用户能集中注意力。

## 位置
默认显示在父级元素的右侧，但开发者可调整位置，以避免覆盖其他重要信息。

1. 父级左侧
2. 父级右侧（默认位置）
3. 父级上方
4. 父级下方

## 构成

1. Container 容器：容器高度根据内容自适应。
2. 图素（可选）：支持图片和视频。如果是视频加载时间过长，建议添加加载动画。
3. Title 标题：文案尽量清晰简洁。
4. Sub Text 副文本（可选）：用来补充说明。
5. Action：可以配置最多 2 个 Action。

## 交互行为
### 出现与消失
只要满足下表中的一种，即可触发 Coach Mark 的显隐。
| **出现** | **消失** |
| --- | --- |
| 1. 点击父元素 ;  2. 页面加载并且正在解释新功能 | 1. 与 Coach Mark 上的 Action 进行交互 ;  2. 点击父元素 |

链接（Link）具备其基本的样式特征。当我们将链接以文字按钮的形式呈现时，与常规按钮相比较，这种链接式文字按钮在视觉上并不那么突出醒目。由于它相对不显眼的特质，在实际的操作设计里，通常会把它用作可选操作的交互方式，以便用户能根据自身需求来自主选择是否执行相关操作。

## 构成
### 内容
链接式文字按钮可分为纯文本形式或文本与图标结合形式。点击会跳转到浏览器进行查看，常用于声明、说明等。

### 尺寸
链接式文字按钮有两种尺寸，分别为 Max 和 Regular。

## 交互行为
链接式文字按钮分为三种交互状态：

1. Normal 默认态：链接式文字按钮在无任何操作且未出现特殊情况时的默认显示状态。
2. Hover 悬停态：当通过手势、手柄或头控操作将光标置于链接文字按钮上方时，按钮进入悬停状态，文字下方会有背景填充，以向用户提示该元素可点击。
3. Pressed 点击态：当按下按钮时，会触发点击事件，同时按钮的背景颜色会发生改变。
4. Disable 不可用状态：由于某些原因，按钮当前处于用户无法操作的状态，呈现置灰显示。

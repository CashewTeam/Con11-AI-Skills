Menu（菜单）是临时出现在页面上的一系列选项或功能列表，用来展示被收纳的操作，仅在用户与其父级元素交互后才出现。

## 位置
菜单通常出现在父级元素的下方或右边。如果下方/右侧间距不足则反向展示。

使用时需避免菜单超出主窗口过多（建议不超过 320dp）。达到最大范围后，子菜单需反向对齐。

## 构成

1. 容器：高度随内容自适应。到达最大高度 480dp 后，可滑动查看更多项。
2. 菜单项：包括文本和可选的副文本、前导图标、尾随图标、尾随文本。
3. 分组：不限制分组数量。

### 菜单项
菜单项可以包含文本、副文本、前导图标、尾随图标、尾随文本。只有文本是必须内容，文本尽量简洁明了。同一菜单的所有菜单项包含的内容应该保持一致。
每项具有 Hover、Pressed 和 Selected 交互状态。不可用的菜单项应将其显示为禁用状态，而不是移除；如果某菜单的所有菜单项都不可用，该菜单本身需要保持可用，以便用户可以将其打开并了解所包含的选项。
### **分组**
分组的两种方式：dividers 和 header，任选其一即可。

* 用 header 分组：常用于同一菜单下有区别较大的分组选项，或对分组进行说明备注。
* 用 divider 分组：轻量分组样式，推荐使用。

## 交互行为
### 筛选
菜单可以与输入框组合使用，当用户开始输入时，菜单项会根据输入的内容进行过滤。随着内容的输入，菜单的高度会动态变化。

### 子菜单
阅读长菜单会花费用户更多的时间和注意力，这意味着他们可能会错过想要使用的命令。如果某个菜单过长，可以使用子菜单来缩短列表，例如浏览器的“书签”。原则上不限制子菜单的级数，但为了保证用户体验，建议菜单深度不超过三层。
悬停至父级菜单项即可打开下属的子菜单。某菜单项下属的所有子菜单均不可用时，它显示为可用状态。

### 选择
菜单项通常有下面三种含义：

* 可打开或关闭的功能：勾号在文案前面。
* 推荐或功能可选项：勾号默认在文案后面，如果右侧有二级菜单符号，则移动到前面。
* 功能操作：单次操作生效，选中后不显示勾号。

### 菜单收起
触发菜单收起的方式有三种：

* 选择了某个选项后，赋值并自动收起菜单。
* 点击非菜单区域，无数据修改，收起菜单。
* 使用系统按键，回到首页或退出应用。

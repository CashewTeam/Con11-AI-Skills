Side Navigation 放置在窗口的前沿位置；对于从左到右的语言来说是左侧，而对于从右到左的语言来说是右侧。它提供了应用信息层级的平面视图，使用户可快捷访问同级内容。

因为 Side Navigation 不可收起，会占据较大空间。当窗口尺寸较小或需要更多空间来显示其他信息或功能时，可以使用 [Tab Bar](/tab-bar) 等更紧凑的导航控件。当应用层级比较复杂时，可以结合 Tab Bar 一起使用，在这种情况下 Side Navigation 作为二级导航。

## 构成

1. 容器：高度跟随窗口，宽度提供两种尺寸。
2. 标题（可选）：需要简明扼要的描述导航页面。
3. 搜索框（可选）：搜索方式和结果展示位置，由开发者自定义。
4. 前导图标：不限制图片格式，推荐使用 SVG。
5. 标签文本：尽量避免文案过长而自动换行。如需换行可在单词之间创建换行，或对较长单词使用连字符。
6. 尾部元素（可选）：可以是独立交互的 Icon Button，也可以是不可交互的 Badge。
7. 分类标题（可选）：不限制分类数量。

### 尺寸
显示高度等于窗口高度，内容超过显示高度需滑动查看更多。宽度提供 272 dp、316 dp 两种，可以根据窗口宽度进行选择，比如窗口宽度为 1280 dp 时，推荐使用 316 dp。
### 分组
提供间距和标题两种分组样式；间距分组常用于简单分类，一般用户不可修改导航内容。标题分组常用于工具管理应用，一般还会提供用户自定义组别内容和标题。

## 交互行为
### 滑动
不限制导航数量，超过显示区域后，滑动查看全部内容，Side Navigation 的头部固定显示。

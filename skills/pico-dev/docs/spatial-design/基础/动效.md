## 动效原则
### 服务于体验
动效存在的目的是清晰的传达界面状态的变化或场景的切换，辅助用户理解自己的操作。如果一个动效没有明确的作用就去掉，避免花哨的效果喧宾夺主，浪费性能。
### 遵循物理规律
动效应尽量遵循物理规律，模拟真实世界的运动，如加速、减速、回弹等效果，既能减少认知障碍，也能让动画看起来顺畅又可信。
### 适合的时长与节奏
动效设计需根据 UI 元素 UI 元素的功能层级和空间尺度动态调整时长与缓动曲线，确保用户既能感知界面变化，又不影响操作流畅性。

* 偏反馈的、提醒的小尺寸 UI 元素，应采用较短的动画时长（< 300ms），配合快节奏缓动曲线，确保操作反馈的即时性与精准性。
* 偏框架的、偏场景的大尺寸元素，建议使用 300ms ~ 800ms 的动画时长，搭配舒缓的曲线，帮助用户完整的感知空间变化的过程。

### Z 轴的运用
空间操作系统与传统操作系统很大不同就是引入了 Z 轴变化，所以我们也可以给 UI 元素设计 Z 轴动画，但是避免幅度过大或过于频繁的改变景深，导致用户眼睛频繁调焦，引发眼部疲劳，在 Z 轴上最好采用轻微小幅动画即可。
### 视野边缘动效
人眼视网膜边缘区域对于光线变化和运动极其敏感（视杆细胞），所以对于视野边缘的动效采用轻微的幅度的变化即可引起用户的注意，避免大幅度动画引起用户不适。
### 做好防眩晕措施
在空间操作系统中，用户对于运动的敏感度更高，偏环境/场景类的大尺寸元素运动时会让用户产生自身在运动的错觉，从而引发生理不适，一般可以采用减小动画幅度，或让物体半透明等方式来减轻不适感。
在空间中用户视角就是第一人称相机视角，非必要情况下不要擅自移动相机，以免引发用户的生理不适，如果必须要做相机移动动画，一定要做好防晕动措施。
避免让用户旋转虚拟世界。虚拟世界的旋转可能破坏用户的稳定性感知，即使旋转由用户控制且动作细微。替代方案：在快速淡出时实现瞬时方向变化**。**
## 动效类型
### **空间动效**
UI 元素在三维空间坐标系中做属性变换动画，涵盖 X、Y、Z 轴上的位移、旋转、缩放等空间变换，以及透明度、颜色等属性变化，也支持三维路径轨迹动画，空间动效主要用于构建系统空间层级关系，创造深度感知。
### **窗口动效**
UI 元素在二维平面容器内做属性变换动画，包含 X、Y 轴的位移、旋转、缩放、颜色等属性变换。动画逻辑和效果与传统平面设备（手机、平板、PC）相同。
### **特效**
通过物理引擎（模拟粒子、流体、布料、刚体等）或着色器技术（材质变化、光照、后处理）生成的视觉效果，用于增强真实感和沉浸度，通常情况下不直接承载交互逻辑。
## 动效曲线
### 弹性动画机制
基于弹簧物理模型，通过模拟弹簧的拉伸与回弹运动实现的动效，能模拟现实中的物理现象，比如重力、惯性、摩擦力等，适合跟手动画，如拖动窗口、操作 3D 模型等过程，能让用户感受到真实自然的 “物理” 互动。
### 贝塞尔曲线动画
通过自定义缓动曲线 **cubic-bezier(x1,y1,x2,y2)** 来控制元素运动速度和节奏，常用于界面元素位置、透明度、缩放、旋转等变化，能够精确控制动画的时长节奏。

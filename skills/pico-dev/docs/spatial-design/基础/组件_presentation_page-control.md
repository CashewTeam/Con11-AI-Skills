Page Control 的每个Dot 都代表平行列表中的一个页面。用户可自定义显示的 Dot 数量，原则上不限制页面的实际数量，实际页数超过显示页数，超过的一侧显示省略样式（2 个连续缩小的点）。

## 构成

1. 当前页面：用户可自定义当前页面的指示符，避免在一个 Page Control 中使用两个以上不同指示符图像。
2. 省略 Dot：表示实际页数大于显示页数

## 交互行为
### 翻页
用户通过点击或左右滑动来实现页面翻页。点击每一个非省略 Dot 都可以精确定位到具体页面，点击省略 Dot 则显示下一页或上一页。
### 自动轮播
Page Control 支持轮播翻页，轮播时长由开发者自定义。与 Page Control 直接交互后停止轮播，如果内容为动图或视频停在最后一帧。滑动页面内容切换后恢复轮播。

文本选择器（Text Selector）是一种用于在文本内容中定位、选取特定文本片段的工具或功能，其核心作用是帮助用户或程序精准获取所需的文本信息，以便进行复制、编辑、分析、处理等后续操作。

## 构成
Text Selector 的构成主要指其在用户界面中呈现的视觉元素和交互形态，不同场景下的选择器视觉表现差异较大，但核心是通过视觉反馈让用户清晰感知 “选择条件”、“匹配范围” 和 “操作状态”。

1. **选择区域高亮**
   被选中的文本背景会显示白色背景，与未选中文本形成明显对比，直观标记选择范围。
2. **选择器**
   * 形态：选择过程中，光标变为 “I” 形（文本输入态），提示用户当前可执行选择操作。
   * 边界控制点：选中文本的首尾会显示微小的拖拽点，允许用户拖动调整选择范围。
3. **辅助操作提示**
   选中文本后，可能弹出悬浮工具栏，视觉上以文字、图标或者用户自定义的形式呈现，引导后续操作。

### 工具栏

* 工具栏中的内容可为文字、图标（Icon）或容器；红色部分的内容可由开发者自行定义，例如颜色。

* 工具栏支持分组，对分组数量和分组位置不设限制

### 尺寸

* 宽度依据内容进行自适应调整，完整显示 Action 的文案。size 的最大宽度设定为 480 dp，当内容超出最大宽度时，支持左右翻页操作。
* 文本选中背景框的高度等于行高。

### 位置
位于选择器起始位置上方 8 dp（实际实现时，距离所选文案 24 dp）；Z 轴高度与 Menu 保持一致，以选择器结束位置进行居中对齐。

如下图所示为线性进度（Linear Progress）。

进度条传达了活动进程的状态，比如：应用内容的加载、提交表单或者保存更新。当有多个项目同时加载时，使用单个进度来显示整组的进度。不要为每个活动添加进度。

* 几乎瞬时完成的进度，不用进度条来表明状态，建议：预期等待时间低于 200ms 时不建议显示进度条。如果进程时间过长，建议让用户可切换至后台等待，不要让用户长时间处于等待不可交互的状态。
* 对于等待时间过长的进程，建议配置终止进程的操作。如果用户可以中断进程而不会带来负面影响，可以配置 “取消” 按钮；如果中断进程可能带来负面影响，如丢失已下载的文件，可以再提供 “暂停” 按钮。

## 交互行为
线性进度条仅支持 **确定性进度**，如果等待时间未知，请使用 [Circular Progress](./spatial-design_基础_组件_status_circular-progress.md)。

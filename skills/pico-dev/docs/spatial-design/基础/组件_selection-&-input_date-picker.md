用户能够在设备上迅速且精准地选取日期或日期范围。借助可视化的交互形式，取代了手动输入日期的繁杂流程，降低输入误差，优化用户体验。

Date Picker 可以直接放在 Window，也可放在 Sheet 内。

## 构成

* **年月导航栏：**
   * 月份 / 年份显示（如 “2024 年 10 月”）
   * 切换按钮：向前 / 向后切换月份或年份

* **星期标题栏：**
   显示星期信息（如 “日” 至 “六” 或 “Sun” 至 “Sat”，支持国际化）。
* **日期网格：**
   * 用网格形式展示当月的日期，一般还会包含上月和下月的部分日期（这些日期显示为灰色，不能选择）。
   * 当天日期、已选日期、禁用日期，这三种日期的样式会有区别。

操作区域可以单选或者多选，选择的时候（不管是单选还是多选），如果选中了不是当前月份的日期，顶部显示的年月会自动跳转。

除采用网格形式展示外，亦可进行上下滚动展示，具体规范可参考《[Time Picker](./spatial-design_基础_组件_selection-&-input_time-picker.md)》。

## 交互行为

* **日期状态反馈**
   分为当月日期、非当月日期、当天以及选中日期

* **辅助操作交互**
   * **触发方式：**点击触发区域（输入框、日历图标）时，弹出日期面板（弹窗式）；嵌入式则直接显示，无需触发。
   * **关闭方式：**点击 “关闭” 按钮，面板关闭；点击 “确定” 按钮，保存信息并关闭面板。

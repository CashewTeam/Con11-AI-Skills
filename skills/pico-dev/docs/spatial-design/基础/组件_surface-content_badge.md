Badge 用于指示通知、计数或信息说明，吸引用户注意、引导操作。Badge 自身不可交互，所以通常位于其他组件内部，如 Tab Bar、Side Navigation 等。

## 构成
### Label Badge

1. 容器：容器尺寸根据内容自适应。
2. 文本（可选）：文案尽量清晰简洁，保持文本的易读性。
3. 图标（可选）

 Label Badge 的尺寸偏小，可以采用强对比的颜色。

### Number Badge

1. 容器：容器尺寸根据内容自适应。
2. 数字：最大值由开发者自定义。
3. 省略号：当提示数量过多时，可以采用省略号。

一般用来指示未读消息，虽然不限制数字大小，但需要确保最大字符数，不会超过父级容器。

### Dot Badge
样式大小固定，通过颜色赋予不同含义。如上图中的好友头像右下角的绿色 Dot Badge，用来表示好友在线。

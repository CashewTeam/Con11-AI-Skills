## 在传统 2D 窗口中，为 Spatial Model View 提供资产

* 资产使用时对位置没特别要求，会完全跟着窗口锚点位置走。
* Spatial Model View 用于在传统 2D 窗口嵌套 3D 内容，SDK 会自动把模型大小调整到窗口能容纳的范围，原理是读取资产的最大包围盒，和窗口大小比较后，调整资产体积。
* 虽然 Spatial Model View 能自动适配大小，但制作这类资产时，仍建议按物体在现实中的实际大小做，以提高资产在空间应用里的复用性。
* 在 DCC 软件制作时，如果多个 mesh 输出为一个资产，会合并包围盒计算。通常把对象包围盒的最长边作为正立方体的边，去适配窗口的最短边，用户无需在 DCC 软件里合并 mesh 调整质心。
* 如果输出 usdz，DCC 软件里设置的 PBR 基础材质就是引擎里用的材质。要是用了编辑器并做了材质编辑，就以编辑器结果为准。在实际头戴设备中，头戴会评估真实环境，给对象模拟光照，保持材质表现。
* 为这种模式提供资产时，要清楚使用需求。要是在同一窗口用大量模型，要尽量减小贴图尺寸和使用数量，优化模型面数。不然会导致加载延迟或视窗卡顿。比如把单个模型面数控制在 1500 面左右，用 1024*1024 分辨率的贴图。

## 在 Volumetric 模式下，为 Spatial View 提供资产

* PICO 官方定义：描述模型在 Spatial View 里的位置，指的是模型 root 相对于 Spatial View 的 back face center 的偏移。在 Spatial SDK 里可以用米设置体积空间的宽、高、深，给 DCC 软件作参考。

## 在 Stage 模式下，为 Spatial View 提供资产

* PICO 官方描述 Spatial View 在 window 里的位置时，指的是 Spatial View 的空间原点，也就是用户头戴设备垂直地面的交点，作为世界空间原点，模型相对于这个点做偏移。Spatial View 的空间是无限大的。
* 对应到 Blender 的世界空间，Blender 的世界原点可以看成头戴用户站立的位置，高度为零。
* 从现实物理角度考虑，用户有视觉盲区。头戴设备进入 Stage 模式，模拟佩戴者视觉，也存在盲区。所以给 Stage 模式布置资源时，要考虑这点，想想用户正常平视佩戴时能看到什么，改变视角才能看到什么。

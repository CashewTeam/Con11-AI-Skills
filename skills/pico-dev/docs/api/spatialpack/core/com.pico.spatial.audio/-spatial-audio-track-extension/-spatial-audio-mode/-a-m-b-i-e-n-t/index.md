# AMBIENT
```kotlin
AMBIENT
```
Ambient audio that considers listener orientation. Audio is mixed based on listener's head orientation but has no positional component. 
When to use : Background environmental sounds (e.g., wind, rain) that should produce directionality as the user turns their head but do not require precise positioning.

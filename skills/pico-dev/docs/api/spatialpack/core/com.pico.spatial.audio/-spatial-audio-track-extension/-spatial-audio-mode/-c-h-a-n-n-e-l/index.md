# CHANNEL
```kotlin
CHANNEL
```
Traditional channel-based audio (stereo, 5.1, etc.). No spatial processing applied. Audio plays as-is from the speakers. 
When to use : Plain 2D audio content that does not need spatial effects, or as a fallback when spatialization is unavailable.

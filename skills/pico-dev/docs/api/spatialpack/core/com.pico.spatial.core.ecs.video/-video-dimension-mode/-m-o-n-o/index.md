# MONO
```kotlin
MONO
```
MONO indicates the video dimension mode is a normal (monoscopic) video, where the content for the left and right eyes is identical. This mode supports 2D, 2D 180, and 2D 360 videos. 
- 
2D 180 refers to a 180-degree panoramic video providing a 180-degree horizontal field of view, allowing viewers to see objects spanning from one side to the other. 
- 
2D 360 refers to a 360-degree panoramic video offering a full 360-degree horizontal field of view and 180-degree vertical field of view (up and down), resulting in a complete panoramic experience without blind spots.

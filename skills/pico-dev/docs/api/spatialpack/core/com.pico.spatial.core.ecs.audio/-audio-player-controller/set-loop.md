# setLoop
```kotlin
fun setLoop(loop: Boolean): Boolean
```
Enables or disables looping for audio playback. 
#### Return
true  if the loop setting is enabled or disabled successfully;  false  otherwise. 
#### Parameters
loop 
true  to enable looping;  false  to play only once.

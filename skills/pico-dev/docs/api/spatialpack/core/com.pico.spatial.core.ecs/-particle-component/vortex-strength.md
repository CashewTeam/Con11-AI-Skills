# vortexStrength
```kotlin
var vortexStrength: Float
```
The strength of the vortex effect. Only available when  isVortexEnabled  is  true . 
This property controls the force of the vortex effect. A higher value will result in a stronger rotation, causing particles to rotate around the vortex axis more intensely.

# attractorStrength
```kotlin
var attractorStrength: Float
```
The strength of the attractor effect. Only available when  isAttractorEnabled  is  true . 
This property controls the force of the attractor effect. A higher value will result in a stronger attraction, pulling particles closer to the specified point in the scene.

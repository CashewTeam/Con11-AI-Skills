# FRONT_AND_BACK
```kotlin
FRONT_AND_BACK
```
Culls both front- and back-facing triangles. 
No faces are rendered for this material. 
Best for: Completely hiding the geometry while maintaining its presence in the scene graph, or for objects that only participate in other non-rendering passes.

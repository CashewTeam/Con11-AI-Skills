# releaseModel
```kotlin
fun releaseModel(name: String)
```
Releases a previously loaded model by its name. 
This function is useful for releasing models that are no longer needed, ensuring efficient memory usage. 
#### Parameters
name 
The name of the model that needs to be released from the  AssetBundle .

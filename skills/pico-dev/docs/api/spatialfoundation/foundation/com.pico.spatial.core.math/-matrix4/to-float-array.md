# toFloatArray
```kotlin
fun toFloatArray(): FloatArray
```
Converts the  Matrix4  instance to a float array. 
The float array sequence is m00, m01, m02, m03, m10, m11, m12, m13, m20, m21, m22, m23, m30, m31, m32, m33. 
#### Return
The converted  FloatArray  of the  Matrix4  instance.

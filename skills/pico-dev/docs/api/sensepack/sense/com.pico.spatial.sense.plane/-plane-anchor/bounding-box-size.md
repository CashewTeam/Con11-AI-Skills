# boundingBoxSize
```kotlin
val boundingBoxSize: Vector2
```
The size of the axis-aligned bounding box (AABB) of the anchor in 2D space. 
This represents the dimensions of the smallest rectangle that fully contains the mesh. The bounding box is axis-aligned, meaning its edges are always parallel to the coordinate axes.

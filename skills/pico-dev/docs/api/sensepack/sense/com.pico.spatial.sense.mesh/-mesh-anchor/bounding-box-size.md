# boundingBoxSize
```kotlin
val boundingBoxSize: Vector3
```
The size of the axis-aligned bounding box (AABB) of the anchor. 
This represents the dimensions of the smallest box that fully contains the mesh. The bounding box is axis-aligned, meaning its edges are always parallel to the coordinate axes.

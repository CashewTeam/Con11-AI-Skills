体感交互包括眼手交互、手势直接交互和手势射线，本文提供体感交互相关的设计建议。
## 眼手交互（注视-捏合）
“注视-捏合”（Gaze-Pinch）是一种高效便捷的交互方式，可以支持用户对较远的目标进行快速的点选。具体操作为：通过视线注视进行导航，来明确要交互的目标对象，用食指和拇指捏合触发对目标对象的交互操作。捏合后移动手部位置可以将对象进行拖拽，双手的操作也可以执行旋转、缩放等交互意图。

如果在一些场景下，开发者需要限定只能通过对这种交互方式进行指定的交互操作，或对这种交互方式进行屏蔽，可以通过对事件来源类型的筛选达成这一目标，眼手注视-捏合的类型标签为`.gazePinch`。
### 建议

* 清晰的交互目标
   你需要将交互目标合理放置在用户易于发现的视线范围内，同时注意色彩与边界的设计，便于用户发现可交互对象，进而更轻松地对目标进行操作。
* 合理的尺寸布局
   需要设计合理的尺寸大小和对象间距来确保界面的可读性和交互准确度，具体控件的尺寸和间距建议值请参考 UI 控件。
* 适宜的交互反馈
   强烈建议你为可交互对象设计适宜的视觉反馈，确保用户对即将发生的交互效果有所预期。出于隐私保护的考虑，对于用户注视点引起的 Hover 事件，我们目前不会将具体信息提供给开发者和应用。我们会为通用 Spatial UI 组件提供默认的悬停效果 Hover Effect，你可以通过配置达成一些自定义效果。

## 手势直接交互
手势直接交互（Hand Direct Interaction）为用户提供符合直觉、便捷的交互能力，用户可以像操作真实世界的物体一样对虚拟对象进行交互。手势直接交互主要通过两种方式进行呈现：触碰（Poke）和 捏合（Pinch）。

* **触碰**
   触碰手势支持用户通过食指指尖对交互对象进行点选，在特定平面内也可以进行滑滚或者拖动。

* **捏合**
   捏合手势支持用户将食指和拇指捏合，对交互对象进行选取，并支持后续的拖拽。双手同时交互也可以实现缩放、旋转等操作。

### 建议

* 恰当的使用场景
   手势直接交互适合用于模拟真实物理世界中的体验， 便于创造符合用户直觉的交互体验。
   * 触碰（Poke）交互适合在物体表面进行点选，也可以支持页面的滑动，但不适合执行空间中的拖拽。
   * 捏合（Pinch）具有更广泛的使用场景，支持对虚拟内容执行物理世界中类似的拖拽。
      捏合主要用于提供自然的近场选取与拖拽体验，其触发范围不一定与开发者为对象配置的碰撞体尺寸严格一致。系统会结合手部姿态、手势识别结果以及近场交互判定范围，对目标对象进行综合判断。因此，捏合更适用于“靠近对象即可自然选取和操作”的场景。
      若应用需要严格的物理接触判定，例如仅在手指与指定碰撞体发生接触时才允许触发操作，建议使用手部追踪（Hand Tracking），并为手部或指尖配置碰撞体，由应用自行实现碰撞检测与交互逻辑。详情参见《[手部追踪](./spatial-sdk_追踪_手部追踪.md)》。

   * 如果你想有针对性的筛选或屏蔽来自某种交互方式的事件，请参考事件来源类型，食指触碰和手指捏合对应的标签类型分别为 `.poke` 和 `.directPinch`。
* 适宜的内容布局
   类似真实世界中手部的活动范围，如果你希望用户使用手势直接对内容进行交互，请将内容放置在用户可触及的距离范围内。同时单个对象的尺寸也应便于用户发现并进行直接的交互。

## 手势射线
手势射线（Hand Ray）是一种直观的远场交互方式，支持用户通过从手部发出的射线和远处的对象进行交互。具体操作为：通过移动或旋转手部位置调整射线发出的姿态，从而控制交互目标的选取；用食指和拇指捏合触发对目标对象的交互操作。捏合后移动手部位置可以将对象进行拖拽，双手的操作也可以执行旋转、缩放等交互意图。

### 建议
做为 XR 设备的常见交互方式，开发者需要注意以下方面以确保手势射线交互的效果：

* 合理的尺寸布局
   需要设计合理的尺寸大小和对象间距来确保界面的可读性和交互准确度，特别是在较远的区域，更大的目标有利于用户通过手势射线更好完成交互任务，具体控件的尺寸和间距建议值请参考 UI 控件。
* 适宜的交互反馈
   强烈建议你为可交互对象设计适宜的视觉反馈，确保用户对即将发生的交互效果有所预期。

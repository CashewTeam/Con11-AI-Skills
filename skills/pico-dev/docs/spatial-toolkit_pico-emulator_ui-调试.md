碰撞体积、空间锚点及环境遮挡等关键逻辑往往是“隐形”的，因此在 3D 空间中调试 UI 元素比在 2D 屏幕上更加复杂。PICO Emulator 的 UI 调试功能旨在打破这一黑盒，将底层的空间数据转化为直观的 3D 辅助图形，帮助你摆脱对日志输出的依赖，大幅提升调试效率。
在 **设置** 面板的调试页面，你可以选择一种或多种 UI 调试模式。

* **声音组件**：显示场景中的音频组件。
* **坐标轴**：显示场景中每个 3D 模型（即包含网格的实体）的坐标轴。2D UI 组件的坐标轴不会被显示。
* **碰撞包围盒**：显示场景中每个添加了 Collision 组件的实体和 2D UI 组件的碰撞包围盒。
* **容器包围盒**：显示场景中空间容器的包围盒。
* **容器裁切**：对于超出容器范围被裁切的模型，被裁切的部分会以黄色高亮显示。
* **模型包围盒**：显示场景中每个 3D 模型（即包含网格的实体）的模型包围盒。包围盒的类型是 AABB（Axis-Aligned Bounding Box，轴对齐包围盒）。2D UI 组件的模型包围盒不会被显示。
* **平面检测**：显示系统检测到的平面。每个平面都有语义标签。平面检测是增强现实（AR）和混合现实（MR）中关键的环境感知技术，用于帮助系统识别现实世界中的平面，从而使虚拟物体能够与真实环境精准交互和融合。
* **空间锚点**：显示空间锚点。空间锚点功能将虚拟环境中的位置与真实世界中的位置进行绑定，从而将虚拟内容锚定在指定的位置。仅当应用处于 Full Space 状态时（即在 Stage 中），才可以使用空间锚点。
* **空间网格**：显示空间网格。每个网格带有语义标签。空间网格是对于空间中真实物体的信息的捕捉和重建。

## 声音组件
勾选 **声音组件** 查看音频源在空间中的位置。对于 Object Audio 组件，你还能查看音源的导向。

## 坐标轴
勾选 **坐标轴** 查看 3D 模型的空间定位。

## 碰撞包围盒
勾选 **碰撞包围盒** 查看 2D UI 组件和 3D 模型的碰撞区域。

## 容器包围盒
勾选 **容器包围盒** 查看空间容器的实际占用空间。

## 容器裁切
勾选 **容器裁切** 查看模型超出容器范围被裁切的部分。

## 模型包围盒
勾选 **模型包围盒** 查看 3D 模型的实际占用空间。

## 平面检测
勾选 **平面检测** 查看系统在现实世界中检测到的平面。

## **空间锚点**
勾选 **空间锚点** 查看空间锚点。

勾选 **空间网格** 查看空间网格。

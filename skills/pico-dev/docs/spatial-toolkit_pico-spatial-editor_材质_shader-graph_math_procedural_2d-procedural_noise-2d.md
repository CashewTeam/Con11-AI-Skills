2D Perlin 噪声生成器。

## **参数说明**

* **Amplitude**：生成噪声的强度。值越高，噪声图案中的变化越明显。
* **Pivot**：噪声的基准值。该值可视为噪声的最小值，并会在输出结果乘以 **Amplitude** 之后加到输出中。
* **texcoord**：用于读取数据以将纹理映射到表面的二维坐标。默认使用当前 **UV** 坐标，其中 **U** 为水平轴，**V** 为垂直轴。

## **节点使用说明**
**Noise 2D** 着色器节点会以程序方式生成 Perlin 噪声图案，可用于为材质增加纹理和变化。在应用 **Amplitude** 和 **Pivot** 之前，所有程序生成的噪声值都在 0 **到** 1 的范围内。

Snack 通知用户应用程序已执行或将执行的过程，它出现在窗口底部，不会遮挡主要内容或重要交互。而且它不会打断用户体验，用户可以继续之前的操作，不强制与 Snack 交互。

## 位置
Snack 距离窗口底部 32 dp，相对窗口 Z 轴前移 32 dp。

## 构成

1. 容器：宽度随内容自适应，最大宽度 480 dp。
2. 前导元素（可选）：不限制内容，常用 Icon 或 Circular Progress。
3. 标题：原则上不限制字数，建议采用简洁明确的文案，便于用户理解和阅读。
4. 副文本（可选）：辅助说明 Snack 提示信息。
5. 操作（可选）：最多放置 2 个 Action。

### 颜色
Snack 容器颜色是 `Color Role：Accent`；Snack 标题颜色是 `Color Role：On Accent`。开发者可以根据应用的特性，修改了 Role 的色值。需要确保修改后的可访问性和视觉对比度。

## 交互行为
### 出现与消失
没有 Action 的 Snack 会在 4s 后自动消失。带有 Action 的 Snack 会一直保持显示，直到用户对 Snack 采取操作或将其关闭。
Snack 出现时不会自动获取到焦点，保持用户在 Snack 出现前的焦点位置。
### 连续的 Snack
同时出现多个连续 Snack，必须按照触发时间依次显示，不能同时显示多个 Snack。

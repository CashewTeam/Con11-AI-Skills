本文以 Blender 为例提供详细的模型指南，您也可以使用其他三方 3D 软件进行模型制作。
## **单位与比例**

* **单位**
   用于确保模型在编辑器中单位比例正常。
* **关键概念**
   * 系统单位 = 物理计算基准（推荐：米制单位）
   * 显示单位 = 视窗可视化参考
* **单位设置**
   1. 在 Blender 主窗口的右侧找到属性面板。
   2. 选择 scene 图标 > Units > Length。
   3. Length 长度默认为 Meters（米）。

### 拓扑优化
优化策略：多用四边面、消灭三角面/N 边面、布线顺结构走。

* **拓扑检查**
   * 布线类型（如：三边面/四边面）
   * 网格密度
   * 几何完整性
* **推荐如何处理**
   * 四边形占比 ≥ 95%
   * 均匀分布无突变
   * 无游离顶点/重叠面

### **法向**

* **多余的法向**
   * 从其他应用程序导入的网格。
   * 通过复杂操作生成的几何体（如布尔 Boolean 对象）。
* **查看法向**
   * 在创建对象时，将自动生成法线，使用这些默认法线可以正确渲染对象。
   * 有时需要调整法线，检查模型法线方向， 内部外翻或拥有孔洞，则一些法线可能指向错误方向。
* **显示法向**
   视图叠加层 Viewport Shading > 几何数据 Geometry > 勾选面朝向 Face Orientation，默认蓝色为正确法线方向，红色为错误法线方向。

* **翻转法向**
   编辑模式 Edit Mode > 网格 Mesh > 法向 Normals > 翻转 Elip，该工具仅用于反转选中面的法线方向。
   由于只有选中面的法线方向会被翻转，故可用于精准调整法线方向（不是朝向，法线总是垂直于面）。

* **重计算**
   * 编辑模式 Edit Mode > 网格 Mesh > 法向 Normals > 向外重算法线方向 Recalculate Outside
   * 编辑模式 Edit Mode > 网格 Mesh > 法向 Normals > 向内重算法线方向 Recalculate Inside
   * 快捷键：`Shift + N` 和 `Shift + Ctrl + N`
   这些工具将重新计算所选面的法线，以使它们指向面所属体的外部（或内部）。体不需要封闭；内部和外部由相邻面的角度决定。这意味着感兴趣的面必须与至少一个非共面的其他面相邻。例如，对于栅格基本体，重新计算法线不会产生有意义的结果。

### 平滑着色与平直着色
网格边缘的外观在三维视口和渲染中被确定为均匀的或定义良好的。在编辑模式下，可以选择单个面来决定哪些面被平滑或压平。
**平滑着色**

* 模型右键 > 物体 Object > 平滑着色 Shade Smooth。
* 使用插值顶点法线，网格面的边缘会变得模糊，观感较为光滑。

**平直着色**

* 模型右键 > 物体 Object > 平直着色 Shade Elat。
* 面的法线是均匀显示的，因此所有被选中的网格的边缘会容易被看到。

### 坐标系

* **全局**
   将变换轴与世界空间对齐。世界轴由视口右上角的导航操控器以及栅格平面显示。

* **局部**
   将变换轴与活动物体的方向对齐。
* **万向节**
   定向变换轴工作方式为可视化物体旋转模式，此模式下物体一次旋转一个轴：旋转轴不垂直于彼此，甚至可能重叠，这种现象称为万向节锁，使动画复杂化。

* **视图**
   将变换轴与视图对齐（这意味着它们会随着您的环绕轨道而变化）：
   * X：左/右
   * Y：上/下
   * Z：接近屏幕/远离屏幕
* **游标**
   将变换轴与 3D 游标对齐。
* **父级**
   对齐变换坐标轴到其父级。

### UV 操作
编辑模式 Edit Mode > 标题栏 > UV。Blender 提供了几种 UV 映射方式。比较简单的投影方法使用三维空间到二维空间的映射公式，将点的位置朝点/轴/面确定的表面插值。更高级的方法可以用于更加复杂的模型，并有更具体的用途。

* **展开**
   * 编辑模式 > UV > 展开
   * 快捷键：`U`
   * 展平沿[缝合线](https://docs.blender.org/manual/zh-hans/4.2/modeling/meshes/uv/unwrapping/seams.html)切开后的网格，可用于有机形体。
   * 选择所有您要展开的面。在 3D 视图中，选择 **UV > 展开** 或 `U` 并选择展开。您也可以在 UV 编辑器中使用 **UV > 展开** 或 `U` 来完成此操作，这种方法将展开所有面并重置之前的结果。展开一次后，UV 菜单将出现在 UV 编辑器中。
   * 一个面的 UV 纹理只需用到图像的局部，而不是整张图像。同样，多个面可以共用图像的同一部分，这样面映射后占用的图像会更少。

* **智能 UV 投射**
   * 编辑模式 > UV > 智能 UV 投射。
   * 智能 UV 投射可根据角度阈值（网格中的角度变化）切割网格，这样可以对自动缝合线的创建方式进行精细控制。对于简单的几何形状，如机械物体或建筑，这是一种很好的方法。
   * 该算法会检查物体的形状、所选面及其相互关系，并根据这些信息和您提供的设置创建 UV 贴图。
   如下示例，智能投射将立方体的所有面映射为上下各三个面的整齐排列，立方体的六个面调整为与原物体表面一样的方形。对于更复杂的机械物体，该操作可以快速、轻松地创建规则、直观的 UV 布局。

* **立方投影**
   立方投影将网格映射到展开的立方体表面。网格被投影至六个分离的平面，创建六个 UV 孤岛。在 UV/图像编辑器中，会产生重叠，不过可以移动。
* **柱形投影**
   要展开一个圆柱体（管形），需要纵向切开它并将其折叠平整，Blender 希望视图是垂直的，管形 “向上” 站立。不同的视图会以不同的方式将管投射到 UV 贴图上，如果使用则会扭曲图像，但是您可以设置手动执行计算的轴。
* **球形投影**
   球形投影与柱形投影类似，但区别在于柱形投影是将 UV 投射到一个平面上，朝向圆柱形状，而球形投影则考虑了球体的曲率，每条纬线的间距变得均匀。球形投影适用于球形形状，如眼睛、行星等。

* **重置**
   * 重置 UV，将每个面映射为填充整个 UV 栅格，赋予每个面同样的映射。
   * 如果使用可重复的图像，物体表面会被重复的该图像覆盖，图像会经调整以适应每个单独的面。使用该展开选项重置映射和撤销所有展开（回到初始状态）。

## PBR 材质
引擎支持 Shader Graph，Cloth，Unlit，PBR 材质，混合模式 Fade，Additive，Masked，Transparent，Opaque。

* PBR 材质球：颜色 Base Color，金属度 Metallic，粗糙度 Roughness，法线 Normal

* 3D材质最终效果示例

### 材质规范

* **材质类型**
   * 金属（如金、铁）：反射颜色由环境决定，Metallic = 1。
   * 非金属（如塑料、木材）：Albedo 为固有色，Metallic = 0。
   * 混合材质（如锈蚀金属）：需绘制 Metallic 过渡区域。
* **基础贴图**
   * Albedo (Base Color)：基础颜色。
   * Normal Map：法线贴图，影响物体表面凹凸。
   * Metallic Map：金属度贴图，控制菲涅尔反射。
   * Roughness Map：控制表面微观粗糙程度。
   * Ambient Occlusion：AO 模拟环境光遮蔽效果。
* **扩展贴图**
   * Height Map：用于视差置换效果。
   * Emissive Map：自发光区域（如灯牌、屏幕）。
   * Opacity Map：透明材质（如树叶、玻璃）。

### 贴图规范

* 贴图常见格式：png、tga、jpeg 等图片格式。
* 贴图常见尺寸：512x512、1024x1024、2048x2048（均为 2 的幂次方）。
* 纹理尺寸适配设备（建议 2K 分辨率内）。

**固有色**（**Base Color ）**定义材质的基础颜色，不包含光照或阴影信息。

* 格式：sRGB 色彩空间
* 命名结构：例如 TeaSet_b

**金属度贴图（Metallic）**标识金属（白色）和非金属（黑色）区域

* 格式：灰度图。
* 控制菲涅尔反射。
* 混合材质使用灰度过渡。

**粗糙度贴图（Roughness）**控制表面粗糙度（黑色=光滑，白色=粗糙）。

* 格式：灰度图控制表面微观粗糙程度。
* 决定材质是镜面反射还是漫反射。

**光影贴图（Ambient Occlusion）**模拟环境光遮蔽效果（增强缝隙/凹陷处的阴影）

* 格式：灰度图。

**法线贴图（Normal）**模拟表面微观细节的凹凸效果（如划痕、砖缝）

* 格式：切线空间法线贴图（通常为蓝紫色，8 位或 16 位）。
* 不改变模型实际几何形状，增强光影细节表现。

**透明贴图（Opacity）**控制材质透明度

* 使用硬边缘 alpha（避免半透明渐变，除非需要羽化效果）。
* PNG 删除透明部分，保留显示。
* TGA（带 alpha 通道，规律黑透白不透）。
* 控制镂空区域（如树叶）。
* 命名结构：例如 Earth_o。

**自发光贴图 （Emission）**使材质表面发光

* 不实际照亮场景（除非使用全局光照）。
* 模拟光源、显示屏等。

目前的外接设备主要是 XR 手柄。手柄是 PICO OS 6 重要的输入设备，具有高效准确的定位追踪，细腻逼真的触感反馈。

* **手柄射线交互**
   手柄射线交互是通过手柄前端发出的射线对目标进行操作的交互方式，具有高效、精确的特点。用户可以通过旋转、移动手柄来调整手柄前端的射线对目标进行瞄准、点选以及后续的拖拽；双手同时使用时，也可以触发缩放、旋转等。

* **手柄直接交互**
   类似于手势追踪的近场直接交互，手柄也支持靠近目标直接进行交互，同样支持触碰（Poke）和 捏合（Pinch）两种方式触发对目标的点选操作。相比手势交互，手柄提供了更加精确的追踪以及更为敏捷的反馈。
   * **触碰（Poke）**
      通过手柄前部的指针触碰交互对象来触发点选，多用于 UI 面板，3D 按钮等目标，在特定平面内也可以进行滑滚或者拖动。

   * **捏合（Pinch）**
      通过按下手柄扳机键等操作触发点选，并支持后续的拖拽。双手同时交互也可以实现缩放、旋转等操作。

* **鼠标交互 (Mouse)**
   系统支持连接蓝牙鼠标进行交互。

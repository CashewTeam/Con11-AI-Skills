USD UV 纹理读取器的 MaterialX 实现。

## 参数说明

* **File**：用作纹理的图像文件。
* **St**：用于将纹理映射到表面时读取数据的二维坐标。该节点会将 st 坐标映射到 uv 图像空间。在 st 图像空间中：
   * 坐标 `(0,0)` 映射到 uv 空间中的 `(0,0)`，表示左下角。
   * 坐标 `(1,1)` 映射到 uv 空间中的 `(1,1)`，表示右上角。
* **Wrap S**：节点处理超出 `0–1` 范围的 `S` 值的方式。
* **Wrap T**：节点处理超出 `0–1` 范围的 `T` 值的方式。
* **Scale**：节点应用到纹理所有分量上的缩放值。节点会将纹理值乘以该参数。
* **Bias**：节点应用到纹理所有分量上的偏移值。节点会先将纹理值乘以 **Scale**，然后再加上该参数。

## 输出说明

* **r**：仅输出纹理的红色分量。
* **g**：仅输出纹理的绿色分量。
* **b**：仅输出纹理的蓝色分量。
* **a**：仅输出纹理的 Alpha 分量。
* **rgba**：纹理的 Color 4 输出，包含：
   * 红色
   * 绿色
   * 蓝色
   * Alpha
* **rgb**：纹理的 Color 3 输出，包含：
   * 红色
   * 绿色
   * 蓝色

## 节点使用说明
节点的 **Wrap S** 和 **Wrap T** 参数用于指定：当 `S` 和 `T` 的值超出常规 `0–1` 范围时，节点应如何处理。**Wrap S** 和 **Wrap T** 参数可以被设置为以下值：

* **black**：超出正常范围的纹理坐标会返回黑色。
* **clamp**：超出正常范围的纹理坐标会被钳制到正常范围内。
   * 大于 `1` 的值会被设为 `1`
   * 小于 `0` 的值会被设为 `0`
* **periodic**：超出正常范围的纹理坐标会被归一化到 `0–1` 范围内，从而实现图像平铺。这基本等价于对坐标应用 **modulo 1** 运算。
* **mirror**：超出范围的坐标会以镜像方式重复。相邻区间会交替翻转，因此纹理会呈现“镜像平铺”的效果。

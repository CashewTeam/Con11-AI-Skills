通常指的是文本区域，是一个允许用户输入多行文本的界面元素，常见于表单、编辑器等场景中。

## 构成

* 输入区域主体：核心可视区域，用于显示用户输入的文本内容，通常为矩形框，与单行文本框（Text Input）不同，它支持输入换行、段落等格式，适用于需要输入大量文本的场景，例如问题反馈、邮件正文编辑、文档编辑器等。

* 占位文本：当输入区域为空时显示的提示文字（如 “请输入详细描述”），颜色通常为浅灰色，用户开始输入后自动消失。作用是引导用户理解输入要求，减少认知成本。

* 滚动条：当输入内容超出可视区域时出现，分为垂直滚动条（常见）和水平滚动条（少见，通常通过自动换行避免）。一般采用隐藏式滚动条（仅在内容溢出时显示），减少视觉干扰。

* 位于输入区域下方，用于显示补充信息：
   * 字符计数（如 “50/200 字”）
   * 格式提示（如 “支持换行，不超过 3 行”）
   * 错误提示（如 “内容不能为空”，通常为红色文字）

## 交互行为
文本区域（Text Area）的交互行为是用户与输入框之间的操作反馈逻辑，涵盖从激活到输入、修改再到状态变化的全流程。以下是最常用的基础操作：
| **交互** | **说明** | **placeholder** | **value** |
| --- | --- | --- | --- |
| Idle | 未被激活、无用户操作的状态,文本区域既未获得焦点，也没有用户正在进行输入、编辑等交互行为，主要表现为 “等待用户触发操作” 的静默状态。 |  |  |
| Hover | 当通当手势等其他方式扫过文本区域，文本区域进入悬停状态，背景色发生变化。 |  |  |
| Focused ;   | 点击显示光标（闪烁的竖线或方块），指示输入位置。 |; 光标显示在 Placeholder 前，透明度30% |; 光标在 Value 的后面 |
| Typing | 用户通过虚拟键盘输入字符，光标随输入内容自动后移，文本实时显示在区域内。 |  |  |
| Error | 输入不符合规则（如包含禁止字符）时，会通过边框变红、轻微抖动等方式强化提醒。 |  |  |
| Disable ;   | * 交互限制：无法点击、聚焦，光标不会出现，键盘输入无效。 ;  * 视觉提示：背景色变灰，文本颜色变暗，表示 “不可操作”。 |; |  |

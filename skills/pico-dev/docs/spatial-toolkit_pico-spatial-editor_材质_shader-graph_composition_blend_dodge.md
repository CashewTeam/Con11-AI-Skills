是一种混合操作，根据前景使背景层变亮。计算公式为 `B/(1 - F)`。

## **参数说明**

* **Foreground**：前景输入，在公式中记作 `F`。
* **Background**：背景输入，在公式中记作 `B`。
* **Mix**：混合操作的权重。**Mix** 值越高，混合运算的强度越大，视觉效果也越明显。默认值为 `1`。取值超出 `0` 到 `1` 范围时，会产生超出该节点预期功能之外的未定义效果。

## 节点使用说明
**Dodge** 节点会根据前景中对应区域的亮度，对背景中的各个区域进行提亮处理。计算公式为 `B/(1-F)`。

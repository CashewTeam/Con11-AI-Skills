图标在界面中用来指代常见的内容、操作和模式。它是界面中不可或缺的元素，一定程度上取代了复杂的文本信息，减小了用户的理解成本。PICO Design System 图标风格偏锐利、几何化，即使在较小的比例下仍然清晰可辨。如果应用使用了 PICO Design System，请遵循本绘制规范，若使用个性化品牌设计，只需确保图标的一致性和可读性即可。
## 设计原则
#### 视觉一致性
同一应用中的图标需要在视觉大小、透视和风格上保持一致，便于用户理解和传达品牌风格。

#### 保持语义一致
应用内，一个含义通常只使用一个图形。如所有代表 “拍摄” 语义的统一使用相机这一图形，而不能再使用其他图形去表示。但可以改变图形的附属，来表示不同的状态，如使用不同数量的音浪来表示音量大小。

#### 保持图形内部视觉对齐
某些图标（尤其是非对称图标）按像素居中或对齐，可能会出现视觉不平衡。可以灵活调整图标位置，使其在视觉上达到居中对齐。

#### 图形中包含文本阅读信息
如果图标中出现了字符，或代表文本格式、阅读顺序等信息，在应用本地化时，请确保这些图标符合本地化规范。

#### 使用格式
为了保证渲染清晰度，建议使用 SVG 格式。
## 绘制规范
#### 尺寸与网格
图标内容尽量保持在活动区域内，避免图像被裁切或隐藏。如果需要额外的视觉重量，内容可以延伸到填充区域。

#### 造型
同一图形可以有线性和面性两种样式，根据使用场景可以选择不同的样式，但要保证两者结构造型上保持统一。面性图标相比线性图标的视觉重量会更大，如果图标有层级关系时，面性图标的层级 > 线性图标的层级。比如在 Tab Bar 中未选中项可以使用线性图标，选中项使用面性图标。

#### 圆角
为了遵循 PICO Design System 设计语言中的 “温暖、自然”，图标需要使用圆角进行修饰。外圆角的大小受到图形尺寸的影响，下面列举说明。

* 大圆角 3 dp：用于较大的矩形，形成图标的基础框架。
* 中圆角 2 dp：用于较小的、次要的形状，或在大圆角过于圆滑、使用锐角的情况下。
* 小圆角 1 dp：用于细节转角等地方。

  线性图标的内圆角等于外圆角减去线宽，内部线条与外部轮廓的切角为 0 dp。

#### 斜线与切口
代表删除和取消的斜线应该是 `左上-右下` 的走向 45˚ 贯穿整个图标。斜线粗细为 2 dp，切口默认为 1.5 dp，但如果影响了主体的识别性，可灵活调整。
切口和倾斜角度以 45 度的整数倍。

| 切口大小默认 1.5 dp | 切口大小为 45˚ 倍数 | 倾斜角度为 45˚ 倍数 |

#### 面性与负空间
为了保证视觉大小一致，面性图标的基础形需要比线性图标略小。为了识别性负形可以适当放大，主体图形线条粗细最小尺寸为 1.5 dp。

| 负形适当放大 | 负责图标不能直接填充线性图标 | 保证主体图形的识别性 |
| --- | --- | --- |
|  |  |  |
#### 角标
角标默认显示在主体的右下角。角标和主体应当有一定间距（默认 2 dp），尽量保证切口和角标轮廓保持平行。角标应避让图标主体的重要部分，不影响对主体图形的识别，因此可以灵活调整其位置。

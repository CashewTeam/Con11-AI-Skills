本文介绍 Spatial Editor 中的物理组件。
物理组件可以被添加到实体或从实体中删除。在 .usda 文件中，物理组件的类型为 `SpatialComponent`。这是一种由 Spatial Editor 定义的、非 USD 原生的组件类型。
## RigidBody

该组件为实体赋予物理属性，使其可以响应重力、碰撞和力的作用。
| **参数** | **说明** |
| --- | --- |
| Mode | 设置刚体的物理模式： ;; * **Dynamic**：刚体完全受物理引擎控制，会响应重力、碰撞和力的作用。 ;  * **Kinematic**：刚体不受力或重力的影响，其运动由动画或代码直接控制。 |
| AffectedByGravity | 控制实体是否受重力影响。默认为是。 |
| Mass | 实体的质量（KG）。默认为 1。 |
| Center Of Mass | 定义实体在局部坐标系中的质量中心点位置。默认为（0, 0, 1）。 |
| Inertia  | 惯性张量是描述物体旋转惯性特性的二阶物理张量，表征物体对旋转运动状态改变的抵抗能力。默认为（1, 1, 1）。 |
| Linear Damping | 与运动方向相反的阻力，其数值越大，速度衰减越快。默认为 0，表示没有阻力。  |
| Angular Damping | 与旋转方向相反的阻力，其数值越大，旋转速度衰减越快。默认为 0.05。 |
| Collision Detection | 设置碰撞检测的方式，不同模式在精度和性能开销上有所不同： ;; * **Discrete**：仅在每个物理时间步结束时检测碰撞。此模式性能开销最小，但可能导致高速移动的物体穿过其他薄物体（即“隧道效应”）。 ;  * **Continuous**：通过预测物体在时间步内的运动轨迹来计算碰撞，可以防止“隧道效应”。此模式会增加计算开销，适用于子弹等高速物体。 ;  * **Continuous Dynamic**：仅当两个动态刚体（非静态或运动学刚体）都启用了连续检测时，才在它们之间执行连续检测，是一种性能优化。 ;  * **Continuous Speculative**：一种计算成本较低的连续检测方法。它通过推测性接触来防止穿透，在性能和精度之间取得了平衡。 |
| Translation Locked | 限制刚体沿 x、y、z 中的一个或多个轴的位移。 |
| Rotation Locked  | 限制刚体沿 X、Y、Z 中的一个或多个轴的旋转。 |
## Collision

给物体添加碰撞体。
| **模块** | 参数 | **说明** |
| --- | --- | --- |
| Collision | Mode | 设置碰撞体的行为模式。 ;; * **Collider_Full**: (默认值)标准的物理碰撞体。可以与其他碰撞体发生真实的物理碰撞，例如反弹或阻挡。 ;  * **Trigger_Full**: 完整功能的触发器。它不会产生物理碰撞效果，但可以检测其他物体是否进入、停留或离开其范围，常用于触发脚本或事件。 ;  * **Trigger_Lite**: 轻量级触发器。功能与 **Trigger_Full** 类似，但计算开销更小，性能更高。 |
|  | Shape | 设置碰撞体的几何形状，可选项包括： ;; * **Box**：（默认）矩形碰撞体。; * **Sphere**：球形碰撞体。; * **Capsule**：胶囊形碰撞体。  |
|  | Translation | 碰撞盒相对于物体原点的局部偏移。你也可以单击 **Recalculate** 按钮，Spatial Editor 会根据模型网格自动计算。 ;  该参数仅在 **Shape** 参数为 **Capsule** 或 **Box** 时出现。 |
|  | Rotation | 碰撞体在局部坐标系中的旋转角度。你也可以单击 **Recalculate** 按钮，Spatial Editor 会根据模型网格自动计算。 ;  该参数仅在 **Shape** 参数为 **Box** 时出现。 |
|  | Size | 碰撞体在局部坐标系中的尺寸大小。你也可以单击 **Recalculate** 按钮，Spatial Editor 会根据模型网格自动计算。 ;  该参数仅在 **Shape** 参数为 **Capsule** 或 **Box** 时出现。 |
|  | Height | 碰撞体在局部坐标系中的高度。你也可以单击 **Recalculate** 按钮，Spatial Editor 会根据模型网格自动计算。 ;  该参数仅在 **Shape** 参数为 **Capsule** 或 **Box** 时出现。 |
|  | Radius | 碰撞体在局部坐标系中的半径大小。 |
| Collision Filter ;   | Group | 为实体指定其所属的碰撞组： ;; * **Default**：（默认）默认碰撞组。 ;  * **All**：实体属于所有碰撞组。 |
|  | Mask | 定义实体允许与之发生碰撞的目标碰撞组集合： ;; * **Default**：表示实体仅与归属默认碰撞组的实体发生碰撞。 ;  * **All**：（默认）表示实体可与场景中所有碰撞组的实体发生碰撞。 |
| Physic Material | Static friction | 刚体静止时其表面的摩擦力，默认值为 0.8。 |
|  | Dynamic friction | 刚体在运动时的表面摩擦力，默认值为 0.8。 |
|  | Restitution | 刚体表面的弹性系数，表征实体碰撞后动能保留的比例。取值范围为 0 ~ 1，值越大则实体碰撞后的弹性越强，保留的速度比例越高，反弹效果越明显。默认值为 0.8。 |
## Physics Velocity

设置刚体的线速度和角速度。
| **参数** | **说明** |
| --- | --- |
| Linear Velocity | 定义刚体沿世界坐标系 X、Y、Z 轴的线速度。 |
| Angular Velocity | 定义刚体沿世界坐标系 X、Y、Z 轴的角速度。 |
## Physics Force

为刚体施加力和扭矩，以控制其在物理模拟中的运动。
| **参数** | **说明** |
| --- | --- |
| World Force | 定义一个在世界坐标系中施加于刚体的力。单位是牛顿（N）。  |
| Local Force | 定义一个在刚体自身坐标系（本地坐标系）中施加的力。单位是牛顿（N）。  |
| World Torque | 定义一个在世界坐标系中施加于刚体的扭矩。单位是牛顿·米（N·m）。 |
| Local Torque | 定义一个在刚体自身坐标系（本地坐标系）中施加的扭矩。单位是牛顿·米（N·m）。 |

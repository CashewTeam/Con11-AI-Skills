作为 PICO 开发者，你可能需要为以下类型的通用事件设计交互方式。

为通用事件设计交互方式时，你需要遵循以下原则：

* **易用性**：各类事件的交互体验尽量易用，不会造成过大的生理或心理负担。
* **统一性**：各类交互方式的事件响应尽量统一，与物理体验直觉适当统一，与传统交互方式经验酌情统一。
* **兼容性**：尽可能支持多种交互方式（如手势、眼动等），适配不同的用户场景和诉求。

| 事件 | 图示 | 描述 | 建议 |
| --- | --- | --- | --- |
| Hover ;  悬停 ;   |  | Hover 就是指用户用视线看向、或用手指靠近、或者是控制器射线等交互方式的指针悬停在交互对象上，并没有实际发生操作，但会获得反馈提示。 | * 对交互目标设计合理的尺寸布局，避免距离用户过远或过近，避免过小的视野占比，以便用户容易发现交互对象。 ;  * 避免设计过快移动的交互目标，以便用户能够更稳定地瞄准它们。 ;  * 采用合理的反馈效果，增强用户预期的确定感。使用我们提供的组件将帮你自动完成一部分 Hover 效果。 |
| Tap/Click ;  点选 |  | 捏合一下指尖，食指触碰一下交互对象，或按一下手柄扳机，来点击虚拟物体或 UI 元素的操作，类似传统屏幕的点击，是 XR 中最基础的确认交互。 | * 同样建议你采用有效的触发反馈效果，遵循默认组件效果或自定义。 ;  * 注意事件生效的时长和空间范围，避免体验上长按与拖拽等操作混淆。 ;; |
| LongPress ;  长按 |  | 较长时间持续捏合指尖，或持续用指尖触碰，以及长按手柄扳机，会对虚拟物体触发长按事件，常用于唤起菜单等特殊功能。 | * 设置合理的反馈效果，避免用户长按过程中的迷茫。 ;  * 注意事件生效的时间和空间阈值，避免体验上与拖拽、点选等操作混淆。 |
| Drag ;  拖拽 |  | 手指捏合，指尖触碰或按下手柄扳机之后，保持和交互对象的关系，并移动手或手柄，就会触发拖拽事件了，一般用来使物体跟随移动，调整位置。 | * 避免过于频繁且长距离拖拽，引起用户疲劳。 ;  * 注意事件生效的时间和空间阈值，避免体验上与点选等操作混淆。 ;  * 建议你使用通用事件提供的参数，确保拖拽效果自然流畅。 |
| Scale ;  缩放 |  | 缩放就是指用双手对目标点选后，通过改变两只手对应的远近距离，来控制目标物的大小。 | * 使用通用事件提供的缩放效果，保持相对自然的缩放中心和倍率。 ;  * 限制合理的缩放倍率范围，防止物体过小丢失或过大遮挡场景。 |
| Rotate ;  旋转 |  | 类似缩放操作，改变双手对应的空间角度也可以对目标对象进行旋转。 | * 我们也建议使用通用事件提供的旋转效果，保持相对自然的旋转中心和速度。 |

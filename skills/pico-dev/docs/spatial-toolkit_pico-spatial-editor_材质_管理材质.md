本文介绍如何在 Spatial Editor 中管理材质。
## 创建材质
参见以下步骤了解如何创建材质。

1. 在 **Hierarchy** 窗口，单击 **+**，在下拉菜单中选择 **Materials**，然后选择一种着色器类型。Spatial Editor 会创建一个材质节点。
   在 Spatial Editor 中，材质可以使用内置着色器（包括 Cloth、Unlit 和 Physically Based）和通过 Shader Graph 创建的自定义着色器。详情参阅 [着色器](./spatial-toolkit_pico-spatial-editor_材质_着色器.md)。

2. 按需为创建的材质节点命名。
3. 选中你创建的材质节点，在右侧的 **Inspector** 窗口按需为材质配置参数。详情参阅 [材质参数说明](/editor/manage-material)。

## 把材质关联到实体
在传统的模型制作流程中，为每个实体单独绑定材质通常效率低下，尤其当需要让多个实体共用材质或统一更换新材质时，重复操作会非常繁琐。
在 Spatial Editor 中，每个实体默认都关联了 Material Bindings 组件。该组件会自动应用到该实体及其所有子实体。要让多个网格共用同一材质，你只需将它们全部放置于一个父实体下，然后为该父实体的 Material 组件指定材质。这样，所有子实体都会自动继承并使用该材质，无需再逐一设置。
参见以下步骤了解如何把材质关联到实体。

1. 在 **Hierarchy** 窗口，选中需要关联材质的实体。
2. 在右侧的 **Inspector** 窗口，找到 **Material Bindings** 组件，然后单击 **Binding** 参数旁边的下拉箭头，从列表中选择你想要关联的材质。

## 材质参数说明
不同的着色器类型对应着不同的参数设置。
### Physically Based

基于物理的材质，支持漫反射、高光、金属度、粗糙度、透明度等参数。
| 参数 | 说明 |
| --- | --- |
| **Blending Mode** | 混合模式，定义材质如何与背景混合。 ;; * **Opaque**: 不透明，完全遮挡背景。 ;  * **Transparent**: 透明，根据 Alpha 混合。 ;  * **Fade**: 淡入淡出，物体会逐渐消失。 ;  * **Masked**: 遮罩，根据阈值剔除像素。 ;  * **Additive**: 叠加，颜色与背景相加。 |
| **Face Culling** | 面剔除，决定渲染时剔除哪一面以优化性能。 ;; * **None**: 双面渲染。 ;  * **Front**: 剔除正面。 ;  * **Back**: 剔除背面。 |
| **PBR Mode** | 性能模式。 ;; * **Standard**: 标准 PBR 计算。 ;  * **Fast**: 简化计算以提升性能。 |
| **Base Color** | 基础漫反射颜色 (Albedo)，支持纹理贴图。 |
| **Opacity** | 不透明度 (0.0-1.0)，支持纹理贴图。 ;  **Blending Mode** 为 **Opaque** 时该参数不会出现。 |
| **Metallic** | 金属度 (0.0-1.0)。0.0 为非金属 (绝缘体)，1.0 为纯金属。支持纹理贴图。 |
| **Roughness** | 粗糙度 (0.0-1.0)。0.0 为极度光滑 (镜面)，1.0 为极度粗糙 (漫反射)。支持纹理贴图。 |
| **Normal** | 法线贴图。用于在不增加几何体面的情况下模拟表面凹凸细节。 |
| **Depth Write** | 深度写入。开启后，物体像素深度会被写入深度缓冲区，可遮挡其后方的物体。 |
| **Depth Test** | 深度测试。开启后，仅当像素深度符合比较条件（通常是小于缓冲区深度）时才渲染，即被前方物体遮挡时不渲染。 |
| **Clear Coat** | 清漆强度。模拟覆盖在材质表面的透明涂层 (如车漆、打蜡地板)。 |
| **Clear Coat Roughness** | 清漆粗糙度。控制清漆表面的光泽程度。 |
| **Emissive** | 自发光颜色。模拟物体表面发出的光，不受环境光照影响。 |
| **Ambient Occlusion** | 环境光遮蔽 (AO)。模拟物体缝隙或角落处因光线难以到达而产生的阴影效果。 |
| **Reflectance** | 镜面反射率。控制非金属材质在法线方向的反射强度 (F0)。 |
| **Opacity Threshold** | Alpha 裁剪阈值。低于此值的像素将被丢弃。 ;  该参数仅在 **Blending Mode** 为 **Masked** 时生效，用于定义镂空的判定标准。 |
### Unlit

无光照的材质，它的颜色和外观不会受到任何光照的影响。
| 参数 | 说明 |
| --- | --- |
| **Blending Mode** | 混合模式，定义材质如何与背景混合。 ;; * **Opaque**: 不透明，完全遮挡背景。 ;  * **Transparent**: 透明，根据 Alpha 混合。 ;  * **Fade**: 淡入淡出，物体会逐渐消失。 ;  * **Masked**: 遮罩，根据阈值剔除像素。 ;  * **Additive**: 叠加，颜色与背景相加。 |
| **Face Culling** | 面剔除，决定渲染时剔除哪一面以优化性能。 ;; * **None**: 双面渲染。 ;  * **Front**: 剔除正面。 ;  * **Back**: 剔除背面。 |
| **Base Color** | 基础漫反射颜色 (Albedo)，支持纹理贴图。 |
| **Opacity** | 不透明度 (0.0-1.0)，支持纹理贴图。 |
| **Apply Tone Mapping** | 是否应用色调映射。 ;; * **启用**: 参与后处理曝光和色调调整 ;  * **禁用**: 直接输出原始颜色 |
| **Opacity Threshold** | Alpha 裁剪阈值。低于此值的像素将被丢弃。 ;  该参数仅在 **Blending Mode** 为 **Masked** 时生效，用于定义镂空的判定标准。 |

### Shader Graph

自定义材质。
| 参数 | 说明 |
| --- | --- |
| **Blending Mode** | 混合模式，定义材质如何与背景混合。 ;; * **Opaque**: 不透明，完全遮挡背景。 ;  * **Transparent**: 透明，根据 Alpha 混合。 ;  * **Fade**: 淡入淡出，物体会逐渐消失。 ;  * **Masked**: 遮罩，根据阈值剔除像素。 ;  * **Additive**: 叠加，颜色与背景相加。 |
| **Face Culling** | 面剔除，决定渲染时剔除哪一面以优化性能。 ;; * **None**: 双面渲染。 ;  * **Front**: 剔除正面。 ;  * **Back**: 剔除背面。 |
| **Depth Write** | 是否将物体的深度信息写入深度缓冲区。 ;; * **启用**：将物体的深度信息写入深度缓冲区。物体会遮挡位于其后方的其他物体（通常用于不透明材质）。 ;  * **禁用**：不将物体的深度信息写入深度缓冲区。物体不会遮挡位于其后方的其他物体（通常用于半透明材质，以避免渲染排序错误）。 |
| **Depth Test** | 是否在渲染时检查实体的深度信息。 ;; * **启用**：渲染时会检查深度。如果物体被前面的东西遮挡，则不显示被遮挡的部分（符合物理规律）。 ;  * **禁用**：忽略深度遮挡。物体可能会直接渲染在所有东西上面（常用于 HUD、UI 或透视效果）。 |
| **Opacity Threshold** | Alpha 裁剪阈值。低于此值的像素将被丢弃。 ;  该参数仅在 **Blending Mode** 为 **Masked** 时生效，用于定义镂空的判定标准。 |

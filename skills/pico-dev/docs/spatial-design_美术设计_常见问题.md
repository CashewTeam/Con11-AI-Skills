### 获取网络资源，并通过 Blender 处理

1. 获取一个资产。
   例如：https://polyhaven.com/models
   1. 选择资产并下载相关资产
      * 例如选择了 https://polyhaven.com/a/marble_bust_01
      * 在页面内查看模型描述，如果超过 60 k，推荐换其他模型，顺便确认高度，高度将是你资产在项目中的默认表现。将贴图分辨率改成自己所需的，基本 1 k 够用，2 k 更为细致。下载格式改成 usd，并点击下载。

   2. 点击 **Dowload** 下载，并解压。
   3. 下载资产贴图（直接下载即可），网站的形式为点击后打开纹理自行保存。
      | 点击红框处 ;   | 分别下载 PNG 格式的 diffuse，normal，rough ;   |
      | --- | --- |
2. Blender 处理。
   1. 导入资产
      1. 打开 Blender，清理默认场景。
         | 1. select menu - select all ;; |  |
         | --- | --- |
         | 2. 鼠标右键/mac 双指点触摸版 - Delete |  |
         | 3. （可选）file - clean - purge ;; |  |
      2. 导入 USD 资产。
         | 1. 将解压出来的 USDC 拖入 ;; |  |
         | --- | --- |
         | 2. 全默认，点击 Import ;; |  |
         | 3. 点击红框的图标预览材质，滚动鼠标中键放大缩小，按住鼠标中键拖动改变视角，shift + 鼠标中键拖动观看位置 ;; |  |
      3. 设置材质，建议完全重设，避免图片存储错误的问题。
         1. 选择 **Shader Editor** 进入材质编辑。

         2. 观察棕色栏目的内容。
            这里可看到丢失一个，如果不熟悉可以将棕色栏目的都删掉。

         3. 选择棕色的栏目，鼠标右键，并选择 **Delete**。

         4. 清理文件。

         5. 重新赋予下载的材质（设置基础 PBR）。
            1. 打开之前下载的材质，找到含有 `_diff` 或者是 `Diffuse` 字样的文件。拖入到材质编辑器，并且连接到BaseColor。
               |  |  |
               | --- | --- |
            2. 找到含有 `_norm,_n,_` 或者是 `normal` 字样的文件。拖入到材质编辑器，并且把这个节点的色彩空间改为 non - color，最后连接到紫色 Normal Map 的 Color 节点上。
               |  |  |  |
               | --- | --- | --- |
            3. 找到含有 `_rough,_r,_` 或者是 `roughness` 字样的文件。拖入到材质编辑器，并且把这个节点的色彩空间改为 non - color，最后连接到 roughness 上。
               |  |  |  |
               | --- | --- | --- |
         6. 切回到布局模式，观察结果。
            |  |  |
            | --- | --- |
      4. 导出文件。
         具体参考上文 **导出 USDC/Z（通用）**章节。

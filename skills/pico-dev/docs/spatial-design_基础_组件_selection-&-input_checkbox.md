Checkbox 是用户界面中用于实现 “选择” 功能的交互组件，用户可通过点击操作来选择或取消选择，当处于选中状态时，圆圈内会显示勾选标记（如✓、—）。其核心功能是允许用户从一组选项中选择一个或多个选项（包括全选或全不选），适用于非互斥性的选择场景。

## 构成
Checkbox 可以单独使用，让用户确认某项操作（例如，“不再提示”），也可以组合使用，向用户呈现多项内容。

1. **视觉容器：**样式为圆圈，通常可以通过状态变化直观传递 “选中 / 未选中 / 部分选中” 信息。
2. **标签文本：**
   位置：紧邻视觉容器（通常在右侧，部分场景可在左侧，需遵循界面统一规范）。

### 尺寸
分为 Small、Default 2 种尺寸。两种热区尺寸都是 32 * 32 dp，只是显示大小不同。

## 交互行为
**状态切换：**

* 未选中：空心圆圈
* 选中：实心圆圈，显示勾选标记
* 部分选中：实心圆圈，方框内显示横线 `—`（用于层级选择中的中间状态）

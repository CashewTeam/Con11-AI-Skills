用于从图像中采样数据，并提供在 UV 空间中进行偏移与平铺的功能。

## 参数说明

* **File**：用作纹理的图像文件。支持 .png、.jpg/.jpeg、.bmp、.tga、.hdr 和 .exr 格式的贴图。
* **texcoord**：用于将纹理映射到表面时读取数据的二维坐标。默认情况下使用当前的 UV 坐标，其中：
   * `U` 是水平方向轴
   * `V` 是垂直方向轴
* **UV Tiling**：给定图像沿 `U` 和 `V` 轴的平铺率。在数学上，这等价于将输入的纹理坐标乘以给定的二维向量值。这个平铺率控制 **File** 在纹理中重复的频率。
* **UV Offset**：给定图像沿 `U` 和 `V` 轴的偏移量。在数学上，这等价于从输入的纹理坐标中减去给定的二维向量值。
* **Real World Image Size**：**File** 图像所表示的现实世界尺寸。
* **Real World Tile Size**：单个 `0–1` UV 方形平铺单元在现实世界中的尺寸。
* **Filter Type**：要使用的纹理过滤类型。
   * **Closest**：使用最接近采样位置的纹素值，不进行插值。这种方式不会平滑图像，放大时通常会呈现较明显的像素感。
   * **Linear**：使用线性插值对相邻纹素进行混合。这种方式可产生更平滑的结果，是最常用的纹理过滤方式之一。
   * **Cubic**：使用三次插值进行纹理采样。这种方式通常能得到比 **Linear** 更平滑、更高质量的结果，但开销也可能更高。

## 节点使用说明
**Tiled Image** 节点会以重复平铺的方式将纹理映射到表面。它允许你指定一个纹理图像，并控制其平铺属性以及现实世界尺寸属性。**UV Tiling** 参数会重复给定的文件输入，从而生成一张平铺后的图像。**Real World Image Size** 参数决定该图像的实际尺寸。然后，生成的图像会被应用到一个单独的 `0–1` UV 方形平铺单元上。**Real World Tile Size** 参数决定这个平铺单元的尺寸。这个平铺单元的尺寸与图像的尺寸可以不同。

* 如果图像尺寸大于它要应用到的平铺单元尺寸，那么结果纹理中只会显示图像的一部分。
* 如果平铺单元尺寸大于图像尺寸，那么结果纹理中图像会重复出现。

因此，如果你的目标是重复图像，应使用 **UV Tiling** 参数。虽然你也可以通过 **Real World Image Size** 和 **Real World Tile Size** 参数创建重复纹理，但这些尺寸参数更适合用于描述：

* 图像在现实世界中的尺寸
* 以及它所应用表面的现实世界尺寸

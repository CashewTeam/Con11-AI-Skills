Slider是一种带有被称为 “滚动块” 的水平控制轨道，用户可以通过拖动来选择数值或范围。

* 直观性：通过可视化的轨道和可拖动的滑块头，让用户能快速理解可调节范围和当前选择值。
* 精准度可控：可通过刻度、步长设置（如每次拖动增加固定值）平衡操作效率与选择精度。

## 构成

1. **轨道（Track）：**
   滑块的容器，用于界定用户可拖动的范围。该范围可划分为 “已选区域” 与 “未选区域”（例如，从起点至当前位置为已选区域，其余部分为未选区域），并通过颜色进行区分，以便直观呈现当前所选范围。
2. **滑块按钮（Knob Box）：**
   可拖动的交互元素，用户可通过点击、拖动该元素来改变数值。其样式设计为圆形，以方便用户操作。该元素支持在滑块头处于悬停（hover）状态或被拖动时显示当前数值（采用 tooltip 样式），从而提升交互体验。
3. **图标（icon）：**
   支持在起点处显示图标等辅助元素，使用户能够简便快捷地理解Slider的含义。
4. **刻度 / 标记（Dot）：**
   轨道上的辅助标记，只能在预设的离散数值点间切换，无法选择任意中间值。

支持有极滑块（Stepped Slider）和无极滑块（Continuous Slider）两种滑块类型，主要区别在于数值调节的连续性和精度控制方式：

| **维度** | 有极滑块（Stepped Slider） | 无极滑块（Continuous Slider） |
| --- | --- | --- |
| **数值特性** | 离散值（固定步长） | 连续值（任意中间值） |
| **刻度设计** | 明确刻度对应可选值 | 无刻度或仅参考标记 |
| **操作精度** | 高（严格匹配预设值） | 灵活（支持细腻调节） |
| **典型场景** | 手柄震动调节 | 音量、亮度 |
### 尺寸
尺寸有 Small、Regular、Max 3 种，Regular、Max 可以在左侧配置 Icon。

## 交互行为
### 交互方式
**无极调节：**

* 用户点击滑块按钮（Knob Box）并拖动，使其沿轨道（Track）移动以改变数值，释放按钮后确认选择。
* 支持直接点击轨道任意位置，滑块按钮（Knob Box）将跳转至对应位置并更新数值，以提升操作效率。
* 在移动过程中，若 **Regular** 尺寸的进度小于 40 dp，在 hover、Pressed 状态下无 Dot，与 Normal 状态保持一致。
* 在移动过程中，若 **Max** 尺寸的进度小于 80 dp，在 hover 或 Pressed 状态下无 Dot，与 Normal 状态保持一致。

**有极调节：**

* 拖动吸附：拖动滑块按钮（Knob Box）时，不会随交互行为平滑移动，而是会 “吸附” 到预设的刻度点上。2 个 Knob 之间小于 50% 则吸附过去，如下图则吸附到第 3 个点。

* 点击跳转：点击轨道上的刻度或空白区域时，滑块头会直接跳至最近的有效数值点，而非任意位置（避免选中无效值）。

### 操作热区
有极调节和无极调节两种热区。

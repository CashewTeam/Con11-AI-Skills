一种将前景值与背景值相加的混合操作。其计算公式为：`B + F`。

## **参数说明**

   * **Foreground**：前景输入，在公式中记作 `F`。
   * **Background**：背景输入，在公式中记作 `B`。
   * **Mix**：混合效果的权重。**Mix** 值越高，混合操作的强度越大，视觉效果也越明显。默认值为 `1`。取值超出 `0` 到 `1` 范围时，会产生超出该节点预期功能之外的未定义效果。

### **节点使用说明**
该节点通过 `Mix` 输入控制前景在混合中的权重。`Mix` 值越高、越接近 `1`，混合效果越强；值越低、越接近 `0`，混合效果越弱。

3D 蜂窝噪声生成器。

## **参数说明**

* **position**：用于读取数据以将纹理映射到表面的三维坐标。默认使用当前的三维对象空间坐标。

## **节点使用说明**
**Cellular Noise 3D** 着色器节点以程序化方式生成噪声图案，可用于为材质添加纹理和变化。由于该节点生成的是三维噪声，纹理不会在 **Z** 方向上重复，而是会随着深度变化连续延展。
下面的示例展示了一个节点图，使用 **Cellular Noise 3D** 节点程序化生成黑白图案。将输入的 **Position** 与一个常量浮点值相乘，可以改变生成噪声的频率。数值越大，图案重复得越频繁。该节点的输出随后会经过一个 **Convert** 节点，将浮点输出转换为黑白颜色输出。

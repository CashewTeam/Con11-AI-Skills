* **共享空间，即 SDK 的 Planar、Volumetric **模式下：**
   * 整体三角面不超过 175000 面。
   * 纹理尽量用 2048*2048 及以下分辨率，在使用编辑器的情况下采用默认的 ASTC6x6 压缩，保证包体体积，加快加载速度。
   * Drawcall 保持在 15 个及以下。
   * 活动 Entity 数量保持在 30 个及以下。
   * SkeletonMeshEntity 的骨骼节点数量最好控制在 72 根及以下，且单个顶点对应的权重骨骼不能超过 4 根。
* **独占空间，即 SDK 的 Stage 模式下：**
   * 整体三角面不超过 350000 面。
   * 纹理尽量用 4096*4096 及以下分辨率，在使用编辑器的情况下采用默认的 ASTC6x6 压缩，保证包体体积，加快加载速度。
   * Drawcall 保持在 30 个及以下。
   * 活动 Entity 数量保持在 60 个及以下。
   * SkeletonMeshEntity 的骨骼节点数量推荐控制在 120 根及以下，且单个顶点对应的权重骨骼不能超过 4 根。
* **制作 Image Base Light 用的 exr 资源时：**
   * 要把贴图设置为 R11F_G11F_B10F。
   * 注意如果需要给项目 IDE 的 assets 目录直接提供环境贴图作为照明的话，需要转换为 KTX 格式，且转换后分辨率最好保持在 256 及以下。
   * 编辑器可以直接使用 EXR，HDR 格式的环境贴图，通过组件输出时，编辑器会自动强制转换为 256 分辨率的 KTX 贴图。所以在美术作阶段也无需提供过大分辨率的环境贴图，推荐使用2k到1k分辨率的环境贴图。以保证转换前后的效果正确。

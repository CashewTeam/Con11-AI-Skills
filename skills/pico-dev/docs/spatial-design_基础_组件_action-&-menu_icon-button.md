Icon Button 是界面中以特定图标呈现功能的按钮，通常具备操作直观、节省空间等特性。当执行的操作是用户所熟悉且与图标存在关联时，可考虑采用图标按钮。

## 构成
### 内容
按钮在设计上采用圆形的形状。它具有两种不同的形式，其一是带有背景的形式，背景可以为按钮增添色彩和层次感，使其在页面中更加突出，吸引用户的注意力；其二则是无背景的形式，无背景的纯图标按钮显得更加简洁、简约，能够与各种不同风格的界面进行融合，为用户带来简洁清爽的操作体验。

### 尺寸
分为 Min、Small、Regular、Max 四种尺寸，可根据不同场景和业务需求选择合适的尺寸。

### 角色
Icon Button 一共分为 4 种：

* 主要按钮：采用深色背景搭配浅色图标，此为按钮的默认状态，通常作为用户最可能选择的按钮。
* 次要按钮：使用浅色背景搭配深色图标，适用于无主次之分的场景。
* 其他按钮：呈现浅色背景搭配浅色图标，背景带有模糊效果，常用于图片或文字之上。
* 无背景按钮：在无交互状态下，仅有按钮而无背景，一般在使用相同大小按钮提供两个或多个选项时出现，表明这些选项构成一组连贯选择。

以及两种状态按钮：

* Danger 危险：删除、移动、修改权限等这类具有一定风险性的操作。此类操作可能会对系统数据、文件结构或者软件功能等造成不可逆的影响，进而导致数据丢失、系统故障或者权限混乱等严重后果。为了最大程度地降低因误操作而引发的潜在风险，在执行这类危险操作时，一般都需要进行二次确认。

* Disable 禁用：当此按钮呈现禁用状态时，用户无法对其进行点击等操作。此时按钮会以变灰来直观地向用户表明它当前不能被使用，以避免用户在不适当的时候误触发该按钮对应的功能。

## 交互行为
按钮分为四种交互状态：

* normal 默认状态：按钮在无任何操作且未出现特殊情况时的默认显示状态。
* hover 悬停状态：当通当手势等其他方式扫过按钮时，背景颜色会发生变化.此状态也可作为预示性操作及即时 UI 反馈，让用户能够放心地按下按钮或与按钮进行交互。
* pressed 点击状态：当按下按钮时，会触发点击事件，同时按钮的背景颜色会发生改变。此状态作为对用户的即时 UI 反馈，让用户知道自己已与按钮元素交互。
* disable 不可用状态：由于某些原因，按钮当前处于用户无法操作的状态，呈现置灰显示。

Actived 按钮激活状态：是指按钮在被用户以特定操作选中后所呈现出的一种特定形式。这种形式旨在清晰地向用户传达该按钮当前已被激活、处于被选中或正在发挥作用的状态，按钮背景颜色上会有变化

PICO Spatial Editor（Spatial Editor）是一款 3D 场景构图工具。Spatial Editor 支持以下功能：

* **场景管理**：你无需编写代码即可结合网格、材质、纹理、音频等资源灵活搭建复杂 3D 场景。
* **连接空间应用**：你可以将 Spatial Editor 项目导入到 Spatial 项目，为你的空间应用提供场景支持。
* **自定义着色器**：你可以通过 Spatial Editor 中的 Shader Graph 创建自定义着色器。
* **动画效果器**：你可以通过 Spatial Editor 中的 Timelines 动画效果器创建动画。

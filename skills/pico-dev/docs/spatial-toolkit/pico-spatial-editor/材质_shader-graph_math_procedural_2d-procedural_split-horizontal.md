在指定 U 值处从左到右分割遮罩。

## **参数说明**

* **Left**：分割后左侧区域的值。
* **Right**：分割后右侧区域的值。
* **Center**：控制输出分割位置的坐标值。该参数范围为 **0** 到 **1**。
* **texcoord**：用于读取数据以将纹理映射到表面的二维坐标。默认使用当前 **UV** 坐标，其中 **U** 为水平轴，**V** 为垂直轴。

## **节点使用说明**
该节点沿水平方向创建两个彼此独立的区域，区域的划分由 **Center** 输入值决定。当 **Center** 为 **0** 时，分割位置位于最左侧，因此输出始终等于 **Right** 输入值；当 **Center** 为 **1** 时，分割位置位于最右侧。

从上到下的线性值渐变（梯度）生成器。

## **参数说明**

* **Top**：插值中的顶部值。
* **Bottom**：插值中的底部值。
* **texcoord**：用于读取数据以将纹理映射到表面的二维坐标。默认使用当前 **UV** 坐标，其中 **U** 为水平轴，**V** 为垂直轴。

## **节点使用说明**
该节点使用插值，根据两个值生成一个垂直渐变。输出渐变中的任意一点，都是这两个值的混合结果。某一点在垂直方向上越靠近某一侧，其结果就越接近该侧对应的值。

在指定 V 值处从上到下分割遮罩。

## **参数说明**

* **Top**：分割后顶部区域的值。
* **Bottom**：分割后底部区域的值。
* **Center**：输出发生分割时对应的 **V** 值。高于该值的部分等于 **Top** 输入，低于该值的部分等于 **Bottom** 输入。此参数范围为 **0** 到 **1**。
* **texcoord**：用于读取数据以将纹理映射到表面的二维坐标。默认使用当前 **UV** 坐标，其中 **U** 为水平轴，**V** 为垂直轴。

## **节点使用说明**
该节点沿垂直轴创建两个彼此独立的区域，分割位置由 **Center** 输入值决定。当 **Center** 为 **0** 时，分割位置位于最顶部，因此输出始终等于 **Top** 输入；当 **Center** 为 **1** 时，分割位置位于最底部。

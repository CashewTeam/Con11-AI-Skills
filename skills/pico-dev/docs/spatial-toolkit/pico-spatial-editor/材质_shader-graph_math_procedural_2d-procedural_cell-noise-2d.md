2D 蜂窝噪声生成器。

## **参数说明**

* **texcoord**：读取数据时使用的二维坐标，用于将纹理映射到表面。默认使用当前 **UV** 坐标，其中 **U** 为水平轴，**V** 为垂直轴。

## **节点使用说明**
**Cellular Noise 2D** 节点会以程序方式生成噪声图案，可用于为材质增加纹理和变化。
例如，可将输入纹理坐标与一个常量浮点数相乘，以提高噪声频率，使图案重复得更加频繁。随后再通过 **Convert** 节点，将浮点输出转换为黑白颜色输出，并将结果应用到模型表面。

对用于 2D 纹理放置的 UV 纹理坐标进行变换。

## **参数说明**

* **Texture Coordinates**：要进行变换的输入纹理坐标。默认值为当前表面的纹理坐标，索引为 `0`。
* **Pivot**：用于缩放和旋转纹理坐标的枢轴点。节点会在应用缩放或旋转之前，先从 **U** 和 **V** 坐标中减去该值，之后再将该值加回。
* **Scale**：用于缩放纹理坐标的值。节点会用该值去除 **U** 和 **V** 坐标。默认值为 `(1,1)`。
* **Rotate**：用于旋转纹理坐标的角度，单位为度。正值表示将纹理坐标逆时针旋转，而结果图像顺时针旋转；负值则相反。默认值为 `0`。
* **Offset**：用于偏移纹理坐标位置的值。节点会在完成缩放、旋转并加回枢轴点之后，从纹理坐标中减去该值。默认值为 `(0,0)`。
* **Operation Order：**指定纹理坐标变换操作的执行顺序，包括以下可选值：
   * **SRT**：缩放、旋转、平移。
   * **TRS**：平移、旋转、缩放。

## 节点使用说明
使用 **Place 2D** 节点可以对纹理坐标应用基础变换，例如缩放、旋转和偏移。
例如，枢轴点被设置为 `(0.5, 0.5)`，输入纹理坐标可以被缩小为原来的一半、旋转 180 度，并在 U 和 V 方向各偏移 0.5。由于纹理坐标通常处于 0–1 范围内，枢轴点被设置为 `(0.5, 0.5)` 表示缩放和旋转是围绕图像中心进行的。

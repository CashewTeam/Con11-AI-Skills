通过线性斜率乘数来调整输入值（浮点或颜色）的对比度。

## 参数说明

* **In**: 需要修改的原始输入值。
* **Amount**: 一个线性斜率乘数，用于增加或降低对比度。
   * 当值在 `0.0` 到 `1.0` 之间时，会降低输入 `In` 的对比度。
   * 当值大于 `1.0` 时，会增加对比度。
* **Pivot**: 对比度调整的中心点。
   * 当对比度增加时，输入值会远离此中心值。
   * 当对比度降低时，输入值会靠近此中心值。

## 节点使用说明
以下是一个 Shader Graph 示例，使用 **Contrast** 节点（**Type** 为 **Color3 FA**）来降低一个纹理的对比度，使其颜色更接近灰色。
`Pivot` 的值为 `0.5`，代表灰色。由于 `Amount` 的值是 `0.6`，输入的对比度会降低，同时颜色值向 `Pivot` 输入靠拢。最终，节点的输出纹理变成了原始纹理的灰色版本。

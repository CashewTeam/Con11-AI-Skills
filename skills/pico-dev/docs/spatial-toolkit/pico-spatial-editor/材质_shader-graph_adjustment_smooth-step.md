使用 Hermite 插值法，将一个在 **Low** 和 **High** 范围内的输入值平滑地重新映射到 0 到 1 的输出范围。
如果输入值低于 **Low**，输出为 `0`；如果输入值高于 **High**，输出为 `1`。

## 参数说明

* **In**: 需要重新映射的原始输入值。
* **Low**: 定义了输入值范围的起始点。低于此值的输入将输出 `0`。
* **High**: 定义了输入值范围的结束点。高于此值的输入将输出 `1`。

## 节点使用说明
**Smooth Step** 节点通过 Hermite 插值实现平滑过渡，这与 **Remap** 节点的线性映射有所不同。**Smooth Step** 节点在边界附近提供了更加柔和的曲线，避免了硬切变的突兀效果。

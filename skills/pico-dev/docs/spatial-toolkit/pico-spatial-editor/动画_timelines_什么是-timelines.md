Timelines 是 Spatial Editor 提供的一款动画效果器。通过 Timelines，你可以在不了解动画制作底层技术的前提下，通过预置的动画模板为实体添加动画效果。
Timelines 动画效果器目前处于 Beta 测试阶段，如遇到问题请及时反馈。

* [Timelines 支持的动作](./spatial-toolkit_pico-spatial-editor_动画_timelines_timelines-支持的动作.md)

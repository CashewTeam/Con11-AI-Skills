## 聚焦当前场景
你可以通过以下任一方式把视角聚焦到当前场景：

* 按快捷键 Ctrl + F（Windows）或 Cmd + F（macOS）
* 在 **Hierarchy** 窗口中选中场景的 Root 节点，然后按 F 键。

## 平移视角
按住鼠标中键并拖动，即可平移视角。

## 围绕焦点旋转视角
按住 Option（macOS）或 Alt（Windows）键并拖动鼠标左键，可以围绕焦点旋转视角。此操作常用于从不同角度观察模型资产。

## 旋转当前视角
按住鼠标右键并移动，可以旋转当前视角。该操作模拟了第一人称视角，方便你环顾整个场景。

## 缩放视角
滚动鼠标中键可以缩放视角。另外，你也可以按住 Option（macOS）或 Alt（Windows）键并并拖动鼠标右键。

## 移动摄像机
按住鼠标右键，可使用以下按键在场景中移动摄像机：

* W：向前
* S：向后
* A：向左
* D：向右
* E：向上
* Q：向下

## 调整摄像机的移动速度
按住鼠标右键并滚动鼠标中键，可以调整摄像机的移动速度。

## 快速切换视图
你可以点击视图右上的视图切换器来快速切换视角。各颜色代表的视图如下：

* 蓝色：前视图（其对面为后视图）
* 绿色：顶视图（其对面为底视图）
* 红色：右视图（其对面为左视图）

## 选择场景的坐标空间和投影模式
在视图窗口的右上角，你可以选择场景的坐标空间和投影模式。

可选的坐标空间如下：

* Local：局部坐标
* Global：全局坐标（默认）

可选的投影模式如下：

* Persp：透视
* Ortho：正交（默认）

## 替换场景背景
单击视图窗口的右上角 **Environment Setting** 按钮，你可以在弹出的 **Environment Preview** 窗口中将视图窗口的默认纯色背景替换为不同的环境，以便预览模型在各种光照条件下的显示效果。不同的环境会提供不同的光照。这些背景仅用于在 Spatial Editor 中预览。

**Environment Preview** 窗口包含以下参数：
| **参数** | **描述** |
| --- | --- |
| Background Color | 设置默认背景的背景颜色，不会影响环境光照。 |
| Custom Environment | 开启后，可以使用自定义的图片和内置提供的图片进行环境设置。 |
| Rotate | 沿 Y 轴旋转背景环境，以便于观察模型在不同环境下的效果。 |
| Exposure | 环境光照的曝光强度，用来控制环境光照的亮度。 |
## 选择调试视图
单击视图窗口右上角的 **Debug View** 按钮，你可以从下拉菜单中选择一种调试视图。调试视图是一种特殊的视觉模式，能帮助你更好地理解场景中各类元素及其状态。这些视图仅用于在 Spatial Editor 中预览。

**Debug View** 下拉菜单包含以下选项：

* **Shaded**：显示标准的着色和光照效果。
* **Wireframe**：以线框模式显示模型。
* **Shaded Wireframe**：同时显示模型的着色效果和线框。
* **Base Color**：在无光照模式下，仅显示模型的基础颜色贴图。
* **Lighting**：仅显示场景的光照和法线信息，排除其他视觉效果。
* **Opacity Alpha**：显示半透明材质的 Alpha 通道信息。
* **World Normal**：显示物体表面的世界空间法线和法线贴图。
* **UV Density**：以不同颜色可视化模型 UV 贴图的密度。
* **VertexUV**：显示模型顶点的 UV 坐标值。
* **Derived Metallic**：显示材质的金属度（Metallic）信息，综合了材质属性与贴图。
* **Derived Specular**：显示材质的高光（Specular）信息，综合了材质属性与贴图。
* **Derived Roughness**：显示材质的粗糙度（Roughness）信息，综合了材质属性与贴图。
* **Derived Ambient Occlusion**：显示材质的环境光遮蔽（AO）信息，综合了材质属性与贴图。
* **Derived Emissive**：显示材质的自发光（Emissive）信息，综合了材质属性与贴图。
* **Derived Clearcoat**：显示材质的清漆（Clearcoat）层信息。
* **Derived Clearcoat Roughness**：显示材质清漆层的粗糙度（Roughness）信息。

## 显示或隐藏 Gizmo
单击视图窗口右上角的 **Gizmo Setting** 按钮，你可以在下拉菜单中选择隐藏或显示 Gizmo。

**Gizmo Setting** 下拉菜单包含以下选项：

* **Grid**：地面网格。
* **Colliders**：碰撞体。
* **Particles**：粒子发射器。
* **Audio Sources**：音频源。
* **Lighting**：灯光。
* **Bounding Box**：包围盒。

## 管理摄像机预设
单击视图窗口右上角的 **Camera Presets** 按钮，你可以在下拉菜单中选择保存和管理摄像机预设。摄像机预设功能可帮助你管理摄像机位置，并快速切换到之前保留的摄像机位置。

## 重置摄像机
单击视图窗口右上角的 **Reset Camera** 按钮，可将摄像机的位置重置到场景原点  (0, 0, 0)。

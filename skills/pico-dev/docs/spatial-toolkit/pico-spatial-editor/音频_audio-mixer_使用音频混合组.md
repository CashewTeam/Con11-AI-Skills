本文介绍如何通过音频混合组控制音频文件的播放属性。
你可以在 Spatial Editor 中或使用 PICO Spatial SDK 创建和管理音频混合组。

* **Spatial Editor**：你可以在 Spatial Editor 中创建一个或多个 [Audio Mix Groups](/editor/audio-components) 组件并将其关联到场景中的实体。在 Audio Mix Groups 组件中，你可以添加一个或多个音频混合组，然后向每个音频混合组添加一个或多个音频文件，并在音频混合组中同时控制所有已添加的音频文件的播放属性，包括是否静音、播放速度和增益。
* **PICO Spatial SDK**：通过 PICO Spatial SDK，你可以对音频混合组进行管理。详情参阅 [音频混合组](./spatial-sdk_音频_使用音频混合组.md)。

## 步骤一：创建音频混合组
你可以直接创建音频混合组并将其关联到场景的 Root 节点，也可以创建音频混合组并将其关联到实体。无论关联到哪个实体，Audio Mix Groups 组件都对场景中的全部实体生效。
### 创建音频混合组并将其关联到场景的 Root 节点
在 Spatial Editor 的最下方，单击 **Audio Mixer** 标签。

* 如果场景下没有音频混合组，**Audio Mixer** 标签页会提示你创建一个音频混合组。单击 **Choose** 创建一个新的音频混合组，该音频混合组将自动关联到场景的 Root 节点。

* 如果场景下已经有了音频混合组，你可在 **Audio Mixer** 标签页中单击 **Root** 右侧的 **Create Mix Group** 图标创建一个音频混合组。

### 创建音频混合组并将其关联到实体
你也可以选中需要关联音频混合组的实体，在 **Inspector** 窗口单击 **Add Component**，然后选择 **Audio Mix Groups**。

Audio Mixer 标签页就会出现一个与该实体关联的音频混合组。

### 重命名音频混合组
双击音频混合组的名称可以对其重命名。建议你使用有意义且易于识别的名称。
音频混合组的名称只能包含字母、数字和下划线，且不能以数字开头。

## 步骤二：把音频文件关联到音频混合组
单击音频混合组中的 **+** 按钮，在下拉菜单中选择场景中的音频文件。另外，你也可以单击 **Choose...**，选择一个添加到当前项目中的音频文件。
* 一个音频文件只能属于一个音频混合组。如果你在一个音频混合组中关联了另一个音频混合组中的音频文件，该音频文件会自动从原音频混合组中移除，并关联到新的音频混合组中。
* 如果你需要从音频混合组中取消关联音频文件，选中音频文件后单击 **-** 按钮。

## 步骤三：同时控制音频混合组内所有音频文件的播放属性
在音频混合组中，你可以同时控制所有已添加的音频文件的播放属性，包括是否静音、播放速度和增益。播放属性调整完成后，你可以单击每个音频文件右侧的播放按钮预览播放效果。
每次只能播放一个音频文件。

| 参数 | 说明 |
| --- | --- |
| Mute | 是否静音。开启后，将静音该音频混合组内的所有声音。 |
| Speed | 播放速度。 ;; * **1.00**：表示原始速度。 ;  * **大于 1.00**：加速播放。 ;  * **小于 1.00**：减速播放。 |
| dB | 调整音量（增益）。你可以通过直接输入数值或拖动滑块来设置。你可以同时预览 dB 和 dBSPL。dBSPL 代表声压级，用来模拟声音在物理环境中的真实响度衰减范围。 ;; * **0.0**：代表原始音量。 ;  * **负数**（例如 -10.0）：减小音量。 |

## 后续步骤
Audio Mix Groups 组件不能用于播放音频文件。你需要使用空间音频组件来播放音频文件。详情参阅 [空间音频组件](./spatial-toolkit_pico-spatial-editor_组件_组件类型_音频组件.md)。
当你使用空间音频组件播放音频混合组中的音频时，该音频会自动继承你为该组设定的播放属性。

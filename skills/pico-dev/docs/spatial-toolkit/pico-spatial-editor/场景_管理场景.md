本文介绍如何在 PICO Spatial Editor（Spatial Editor）中管理场景。
## 什么是场景
场景（Scene）定义了一个 3D 空间和其中所有的物体。例如，若你有一个跑车 3D 模型，你可以为其构建一个场景，包含跑车3D模型、LED车灯动态效果（如转向灯闪烁、刹车灯渐变）、车载仪表盘的实时速度/油量数据显示面板，以及模拟驾驶的交互式动画（如方向盘转动、油门响应）和配套音频（引擎轰鸣声、刹车声及转向灯提示音）。通过场景，你的应用可以从单个文件中加载这些资源。

* 在 Spatial Editor 中，场景以 .usda 文件格式存储，其中的每个 Prim 都对应场景树状层级结构中的一个节点。每个节点都是一个实体（Entity）。因此，将资源添加到项目后，你还必须将其作为节点添加到场景中，才能在场景内使用该资源。详情参阅 [管理节点](./spatial-toolkit_pico-spatial-editor_场景_管理节点.md)。
* 在 PICO Spatial SDK 中，作为场景的 `Scene` 类管理多个 `Entity` 对象。一般情况下，一个空间容器承载一个场景，容器内创建的所有 3D 实体都属于该场景。你可以调用 `bundle.loadModel()`加载在 Spatial Editor 中创建的场景。详情参阅 [AssetBundle](/spatial-sdk/asset-bundle/)。

## 创建场景
参见以下步骤在当前 Spatial Editor 项目中创建一个场景。

1. 单击场景标签栏中的加号。

2. 在弹出的对话框中，输入场景名称，设置标签，选择需要保存到的目录，然后单击 **Save**。

3. 你可以在 Spatial Editor 中看到新创建的场景。

## 关闭场景
在场景标签栏中，找到你需要关闭的场景的标签，单击该标签上的关闭按钮，即可关闭该场景。

## 搜索场景
在场景标签栏中，找到场景标签，右击后在下拉菜单中选择 **Find in Project**。Spatial Editor 界面下方的 **Project Browser** 窗口会显示该场景文件。

当前所处理的数据在指定坐标空间中的几何副切线向量。

## 参数说明

* **Space**：着色器定义副切线向量所使用的坐标空间。默认值为 **object**。**Space** 可被设置为以下值。
   * **model**：局部坐标空间。在着色器对几何体应用任何局部形变或全局变换之前的坐标空间。
   * **object**：局部坐标空间。在着色器对几何体应用局部形变之后、但应用全局变换之前的坐标空间。
   * **tangent**：切线空间。以顶点的切线、副切线和法线为基向量构成的坐标空间，常用于光照和纹理计算。
   * **world**：全局坐标空间。在着色器对几何体同时应用局部形变和全局变换之后的坐标空间。

从单个图像或多层图像中的某一层采样数据。

## 参数说明

* **Filename**：用作纹理的图像文件。
* **Texture Coordinates：**用于将纹理映射到表面时读取数据的二维坐标。默认情况下使用当前的 UV 坐标，其中：
   * `U` 为水平方向轴
   * `V` 为垂直方向轴
* **Address Mode U：**节点处理超出 `0–1` 范围的 `U` 值的方式。
* **Address Mode V：**节点处理超出 `0–1` 范围的 `V` 值的方式。
* **Filter Type：**节点所使用的纹理过滤类型。
   * **Closest**：使用最接近采样位置的纹素值，不进行插值。这种方式不会平滑图像，放大时通常会呈现较明显的像素感。
   * **Linear**：使用线性插值对相邻纹素进行混合。这种方式可产生更平滑的结果，是最常用的纹理过滤方式之一。
   * **Cubic**：使用三次插值进行纹理采样。这种方式通常能得到比 **Linear** 更平滑、更高质量的结果，但开销也可能更高。

## 节点使用说明
**Image** 节点可以基于图像文件创建材质。该节点会从单张图像中采样数据，并将其映射到对象表面。**Image** 节点的**Address Mode** 参数用于指定：当 `U` 和 `V` 的值超出通常的 `0–1` 范围时，应如何处理。
**Address Mode U** 和 **Address Mode V** 可以取以下四种值之一来决定其行为。

* **constant**：边界钳制。超出正常范围的纹理坐标会被钳制到正常范围内。
   * 大于 `1` 的值会被设为 `1`
   * 小于 `0` 的值会被设为 `0`

* **clamp：**边缘钳制。超出正常范围的纹理坐标会使用最边缘的像素颜色。

* **periodic：**超出正常范围的纹理坐标会“回绕”到有效范围内。这种行为本质上等价于对坐标应用 **modulo 1** 运算。

* **mirror：**超出正常范围的纹理坐标会以镜像方式处理。

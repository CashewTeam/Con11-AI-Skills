根据真实世界环境信息以及一张 IBL 贴图（可由你提供，也可使用默认贴图），返回环境的漫反射辐射值和镜面反射辐射值。
**Environment Radiance** 节点本身不直接接收 IBL 贴图输入。IBL 贴图通常由场景环境、光照系统或项目默认环境配置提供。该节点会基于当前环境贴图以及输入的材质参数，计算并输出环境的漫反射辐射和镜面反射辐射。

## 参数说明

* **Base Color**：表面的基础显示颜色，即表面在纯白光照下呈现的颜色。
* **Roughness**：表面的粗糙程度。该值范围为 0 到 1.0。0 表示完全镜面反射的表面，1.0 表示最大粗糙度。默认值为 0。
* **Specular**：表面的镜面反射强度，用于表示表面产生镜面反射的程度。
* **Metallic**：用于表示表面是否具有金属属性。金属表面设为 1，非金属表面设为 0。默认值为 0.0。
* **normal**：表面的法线向量。默认值为 (0, 0, 0)。

## 输出说明

* **diffuseRadiance**：表面的漫反射辐射，指光线被表面吸收后再向各个方向散射的部分。
* **specularRadiance**：表面的镜面反射辐射，指光线从表面反射出去的部分。

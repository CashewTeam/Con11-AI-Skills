本文介绍 Spatial Editor 中的灯光组件。
灯光组件可以被添加到实体或从实体中删除。在 .usda 文件中，灯光组件的类型为 `SpatialComponent`。这是一种由 Spatial Editor 定义的、非 USD 原生的组件类型。
# IBL
## Stage Environment Lighting

全局图像基础光照为整个场景提供基础照明，会影响到场景内的所有实体。
| **参数** |  | **说明** |
| --- | --- | --- |
| System Adaptive IBL |  | 用于控制 System IBL 的强度。默认值为 0，取值范围为 0 到 10。System IBL 用于在昏暗环境下与环境光叠加，保证 PBR 材质实体的照明效果。 |
| Intensity Exponent |  | 用于控制图像的亮度。数值越大，图像越亮。你可以根据场景的氛围和需求调整此参数，以达到理想的光照效果。该参数的默认值为 8，取值范围为 -24 到 24。 |
| Rotation |  | 设置图像的旋转角度，默认值为 (0, 0, 0)。 |
| Mode |  | 纹理模式选择。 ;; * **NONE**：不使用任何环境纹理。 ;  * **SINGLE**：（默认）使用一张环境纹理。 ;  * **BLEND**：混合两张环境纹理。 |
| Texture Resource 1 |  | 设置第一张环境纹理。此参数仅在 **Mode** 设置为 **Single** 或 **Blend** 时可用。 |
| Texture Resource 2 |  | 设置第二张环境纹理。此参数仅在 **Mode** 设置为 **Blend** 时可用。 |
| Blend |  | 设置两张环境纹理的混合比例，默认值为 50%。 |
## Environment Lighting Settings

配置实体在当前场景下从全局图像基础光照中接收到的光量。
| **参数** | **说明** |
| --- | --- |
| Scale | 用于调整该实体从全局图像基础光照中接收的光照强度。值越大，实体接收的光照强度越强。 |
## Image Based Light

本地图像基础光照组件，提供一个本地图像基础光照，它将覆盖全局图像基础光照。
| **参数** |  | **说明** |
| --- | --- | --- |
| Intensity Exponent |  | 用于控制图像的亮度。数值越大，图像越亮。你可以根据场景的氛围和需求调整此参数，以达到理想的光照效果。该参数的默认值为 8，取值范围为 -24 到 24。 |
| Rotation |  | 设置图像的旋转角度，默认值为 (0, 0, 0)。 |
| Mode |  | 纹理模式选择。 ;; * **NONE**：不使用任何环境纹理。 ;  * **SINGLE**：（默认）使用一张环境纹理。 ;  * **BLEND**：混合两张环境纹理。 |
| Texture Resource 1 |  | 设置第一张环境纹理。此参数仅在 **Mode** 设置为 **Single** 或 **Blend** 时可用。 |
| Texture Resource 2 |  | 设置第二张环境纹理。此参数仅在 **Mode** 设置为 **Blend** 时可用。 |
| Blend |  | 设置两张环境纹理的混合比例，默认值为 50%。 |
## Image Based Light Receiver

此组件可将实体与一个特定的本地图像基础光照（Image Based Light）关联，使其接收来自该光源的光照。
| **参数** | **说明** |
| --- | --- |
| Image Based Light | 选择一个已添加 Image Based Light 组件的实体。 |
# Lighting
## Grounding Shadow

此组件为包含网格的模型在地面上投射阴影。此组件只能被添加到网格类型的 Prim。
| **参数** | **说明** |
| --- | --- |
| Cast Shadows | 控制该模型是否投射阴影。默认为是。 |
| Receive Shadows | 控制该模型是否接受阴影。默认为是。 |
## Directional Light

此组件用于添加一个方向光源，其光线相互平行，常用于模拟太阳等远距离光源。
| **参数** | **说明** |
| --- | --- |
| Color | 灯光的颜色。 |
| Intensity | 灯光的强度，以勒克斯（流明/平方米）为单位。默认为 1200。 |
| Enable Shadows | 控制是否启用阴影。默认禁用。 |
| Depth Bias | 用于调整阴影的深度偏差，默认值为 0.01。值越大，阴影与物体表面的偏移量越大，可减少阴影失真，但过大可能导致阴影与物体分离。 |
| Culling Mode | 决定在计算阴影时忽略模型的哪些面，以优化渲染性能。 ;; * **None**：不剔除任何面，所有面都将参与阴影计算。 ;  * **Front**：剔除正面，即只有模型的背面会投射阴影。 ;  * **Back**（默认）：剔除背面。只有模型的正面会投射阴影，可以在不影响视觉效果的情况下提升性能。 |
| Projection ;   | 设置阴影的投射方式。 ;; * **Auto** (默认)：自动计算阴影的投射范围。在此模式下，你需要设置 **Maximum Distance**。 ;  * **Fixed**：手动定义一个固定的投射范围。在此模式下，你需要设置 **Z Near**、**Z Far**、**Orthographic Width** 和 **Orthographic Height**。 |
|  |  |
| Maximum Distance | 定义自动投射模式下阴影的最大距离（米）。默认为 5。该参数仅在 **Projection** 参数设置为 **Auto** 时出现。 |
| Z Near | 表示手动定义投射范围时，阴影投射范围的近裁剪面距离（米）。该参数仅在 **Projection** 参数设置为 **Fixed** 时出现。默认为 10。 |
| Z Far | 表示手动定义投射范围时，阴影投射范围的远裁剪面距离（米）。该参数仅在 **Projection** 参数设置为 **Fixed** 时出现。默认为 0.01。 |
| Orthographic Width | 表示手动定义投射范围时，阴影投射范围在正交投影下的宽度（米）。该参数仅在 **Projection** 参数设置为 **Fixed** 时出现。默认为 10。 |
| Orthographic Height | 表示手动定义投射范围时，阴影投射范围在正交投影下的高度（米）。该参数仅在 **Projection** 参数设置为 **Fixed** 时出现。默认为 10。 |
## Point Light

定义一个点光源。
| **参数** | **说明** |
| --- | --- |
| Color | 灯光的颜色，默认为白色。 |
| Intensity | 控制光源的亮度，单位为流明（lm）。默认为 15000。 |
| Attenuation Radius | 控制光源的有效范围，单位为米。默认为 10。 |
## Spot Light

此组件用于添加一个聚光灯光源，其光线从一个点呈锥形射出，常用于模拟手电筒或舞台灯光等效果。
| **参数** | **说明** |
| --- | --- |
| Color | 灯光的颜色，默认为白色。 |
| Intensity | 灯光的强度，单位为流明 (lm)，默认值为 1000。 |
| Attenuation Radius | 控制光源的有效范围，单位为米。默认为 10。 |
| Inner Angle | 聚光灯光锥的内角，单位为度（°），默认值为 45。 |
| Outer Angle | 聚光灯光锥的外角，单位为度（°），默认值为 60。 |
| Enable Shadows | 控制是否启用阴影。此选项默认禁用。启用后，将显示额外的阴影设置参数。 |
| Depth Bias | 用于调整阴影的深度偏差（单位：米），默认值为 0.01。值越大，阴影与物体表面的偏移量越大，可减少阴影失真，但过大可能导致阴影与物体分离。 |
| Culling Mode | 决定在计算阴影时忽略模型的哪些面，以优化渲染性能。 ;; * **None**：不剔除任何面，所有面都将参与阴影计算。 ;  * **Front**：剔除正面，即只有模型的背面会投射阴影。 ;  * **Back**（默认）：剔除背面。这是最常见的设置，只有模型的正面会投射阴影，可以在不影响视觉效果的情况下提升性能。 |
| Clipping Plane ;   | 设置阴影的剪裁范围，用于定义阴影的可见距离。 ;; * **Auto**：（默认）自动计算剪裁范围。 ;  * **Fixed**：手动定义一个固定的剪裁范围。在此模式下，你需要设置 **Z Near** 和 **Z Far** 参数。 |
| Z Near | 表示手动定义剪裁范围时，阴影剪裁范围的近裁剪面距离（米）。该参数仅在 **Clipping Plane** 参数设置为 **Fixed** 时出现。默认为 0.01。 |
| Z Far | 表示手动定义剪裁范围时，阴影投射范围的远裁剪面距离（米）。该参数仅在 **Clipping Plane** 参数设置为 **Fixed** 时出现。默认为 10。 |
| Falloff Exponent | 表示阴影衰减的指数，该参数用于控制阴影从完全不透明到完全透明的衰减速度，数值越大，阴影衰减越快。 默认为 2。 |

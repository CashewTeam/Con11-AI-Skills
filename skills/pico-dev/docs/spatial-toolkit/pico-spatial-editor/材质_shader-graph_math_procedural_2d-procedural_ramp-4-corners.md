四点线性值渐变（梯度）生成器。

## **参数说明**

* **Top Left**：四点插值中左上角的值。
* **Top Right**：四点插值中右上角的值。
* **Bottom Left**：四点插值中左下角的值。
* **Bottom Right**：四点插值中右下角的值。
* **texcoord**：用于读取数据以将纹理映射到表面的二维坐标。默认使用当前 **UV** 坐标，其中 **U** 为水平轴，**V** 为垂直轴。

## **节点使用说明**
该节点使用双线性插值，根据四个角点的值生成一个渐变。输出渐变中的任意一点，都是四个角点值的混合结果。某一点越靠近某个角点，其值就越接近该角点的值。

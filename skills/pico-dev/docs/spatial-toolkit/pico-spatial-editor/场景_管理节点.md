本文介绍如何管理场景中的节点。
## 什么是节点
在 USD（Universal Scene Description）中，Prim 通过父子关系组织成一个树状层级。在树状层级中，每个 Prim 都是一个节点。
在 Spatial Editor 中，场景以 .usda 格式存储。因此，文件中的每个 Prim 都会作为节点显示在 **Hierarchy** 窗口中，该窗口会完整地展示出场景的层级结构。对于场景来说，每个节点都是一个实体（Entity）。

下表展示了不同类型节点的图标及其对应的 Prim 类型。
| **图标** | **Prim 类型** | **描述** |
| --- | --- | --- |
|  | Xform | 包含 Transform 组件的空节点。 |
|  | SkelRoot | 骨骼的根节点。 |
|  | Scope | 不含 Transform 组件的空节点。 |
|  | Mesh | 网格节点。 |
|  | Material | 材质节点。 |
|  | Skeleton | 动画文件的骨骼节点。 |
|  | Joint | 动画文件的关节节点。 |
|  | Animation | 帧序列动画节点。 |
|  | SkelAnimation | 骨骼动画节点。 |
|  | Audio File | 音源文件节点。 |
## 创建节点
场景有一个默认的 Root 节点。你创建的所有节点都会作为 Root 节点的子节点或者子节点的后代节点存在于场景的层级结构中。新创建的节点的坐标默认是  (0, 0, 0) 。
你可以通过以下方法在 **Hierarchy** 窗口中创建节点。

* **为一个节点创建子节点**：选中需要添加子节点的节点，单击 **Hierarchy** 窗口右上角的加号，在弹出的下拉菜单中选择节点类型。

* **为 Root 节点创建子节点**：不选中任何节点，单击 **Hierarchy** 窗口右上角的加号，在弹出的下拉菜单中选择节点类型。

* **把资源拖拽到 Hierarchy 窗口**：你可以从 **Project Browser** 窗口中把资源作为新的节点拖拽到场景的层级结构中。

* **把资源拖拽到视图窗口**：你可以从 **Project Browser** 窗口中把资源拖拽到视图窗口中。资源默认会被添加为 Root 节点的子节点。

下表说明了下拉菜单中可选的节点类型：
| **选项** | **说明** |
| --- | --- |
| Reference | 向当前场景添加一个 Reference，用于引用当前项目中的资源。 |
| Create Empty | 向当前场景添加一个包含 Transform 组件的空节点，即 Xform 类型的节点。 |
| Scope | 向当前场景添加一个不含 Transform 组件的空节点，即 Scope 类型的节点。 |
| Primitive Shapes | 向当前场景添加基础几何体。 ;; * **Capsule**：胶囊体模型。 ;  * **Cone**：圆锥模型。 ;  * **Cube**：立方体模型。 ;  * **Cylinder**：圆柱模型。 ;  * **Sphere**：球体模型。 ;  * **Plane**：平面模型。 |
| Materials | 向当前场景添加材质。 ;; * **PBR（Physically Based）**：基于物理的材质。 ;  * **Unlit**：无光照材质。 ;  * **Cloth**：布料材质。 ;  * **Shader Graph**：通过 Shader Graph 构建的自定义材质。 |
| Particle Effects | 向当前场景添加粒子效果。 |
| Lights | 向当前场景添加灯光。 ;; * **Directional Light**：平行光，支持阴影。 ;  * **Point Light**：点光，不支持阴影。 ;  * **Spot Light**：聚光灯，支持阴影。 |
| Audio | 向当前场景添加音频。 ;; * **Object Audio**：空间音频，有方向和位置。 ;  * **Ambient Audio**：环境音频，只有方向没有位置。 ;  * **Channel Audio**：普通音频，没有方向和位置。 ;  * **Audio File**：一个音源文件。 |
## 选中节点
在 **Hierarchy 窗口** 单击需要选中的节点即可选中该节点，选中后可进行查看、删除、重命名等操作。

如果你需要选中多个节点，可以按住 Ctrl 键（Windows）或 Command 键（macOS）的同时：

* 依次单击需要选中的节点。
* 先单击一个节点作为起点，再单击一个节点作为终点。起点到终点的所有节点都会被选中。

## 定位节点
你可以在 **Hierarchy** 窗口中双击节点来快速在视图窗口中定位到该节点。

## 查看节点
在 **Hierarchy 窗口** 选中一个节点后，你可以在右侧的 **Inspector 窗口** 查看当前节点的详细信息。

## 删除节点
在 **Hierarchy 窗口** 选中一个节点后，右击该节点，在弹出的下拉菜单中单击 **Delete**。

## 重命名节点
右击节点，选择 **Rename**。另外，你也可以在 **Inspector** 窗口双击节点名称来对选中的节点进行重命名操作。
节点名称的首字符只能是英文字母或下划线。

## 移动节点
你可以通过拖拽调整节点在层级中的位置。

## 隐藏或显示节点
每个节点右侧都有一个控制可见状态的眼睛按钮。点击该按钮切换节点在场景中的显示/隐藏状态。你也可以选中并右击节点，在弹出的下拉菜单中选择 **Enable** 或 **Disable**。隐藏后，该实体将无法被渲染，也无法与物理系统交互。

## 启用或停用节点
右击节点，选择 **Activate** 或 **Deactivate**。被停用的节点会从当前场景中被移除，但你可随时重新启用将其恢复到场景中。

另外，你也可以在 **Inspector** 窗口单击 **...**，然后在下拉菜单中选择 **Activate** 或 **Deactivate**。
## 锁定或解锁节点
每个节点右侧都有一个控制锁定状态的锁按钮，点击该按钮切换节点的编辑/不可编辑状态。另外，你也可以选中并右击节点，在弹出的下拉菜单中选择 **Lock** 或 **Unlock**。

## 节点编组
选中一个或多个节点，然后右击并选择 **Group**。Spatial Editor 将自动创建一个名为 Group、类型为 Xform 的新父节点，并将你选中的所有节点作为子节点移动到其下方。

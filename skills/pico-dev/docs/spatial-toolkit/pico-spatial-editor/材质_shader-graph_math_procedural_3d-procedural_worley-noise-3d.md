3D Worley 噪声生成器。

## 参数说明

* **position**：节点读取数据时所使用的三维坐标，用于将纹理映射到表面。默认情况下，使用当前的**对象空间 3D 坐标**。
* **Jitter**：每个单元中心点发生抖动或偏移的程度。默认值为 **1.0**。较小的值会产生更规则的图案，而值为 **0** 时会生成完美的方格。

## 节点使用说明
**Worley Noise 3D** 节点可生成不均匀的细胞状区域。该节点会创建有限数量的中心点，而每个区域都是围绕距离某个中心点最近的位置形成的多边形区域。由于该节点生成的是 3D 噪声，纹理不会在 Z 方向上重复，而是会随着深度变化持续延伸。
下面是一个节点图示例，展示如何使用 **Worley Noise 3D** 节点生成黑白图案。将输入的纹理坐标与一个常量 Float 相乘，这会改变生成噪声的频率。数值越高，图案重复得越频繁。然后将输出传入一个转换节点，把它转换为黑白颜色值。

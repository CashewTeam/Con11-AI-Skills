根据 **Mix** 值的权重，对前景输入与背景输入进行混合。计算公式为：`F*m + B(1 − m)`。

## **参数说明**

* **Foreground**：前景输入，在公式中记作 `F`。
* **Background**：背景输入，在公式中记作 `B`。
* **Mix**：决定输出结果更接近前景还是背景的权重值。默认值为 `0`。取值超出 `0` 到 `1` 范围时，会产生超出该节点预期功能之外的未定义效果。在数学公式中记作 `m`。

## **节点使用说明**
**Mix** 节点用于将两个输入值混合在一起。
当 **Mix** = 1 时，输出结果与 **Foreground** 完全相同；当 **Mix** = 0 时，输出结果与 **Background** 完全相同。`Mix` 值越接近 `0` 或 `1`，输出结果就越接近对应的输入。
**Mix** 节点可用于在两种不同纹理之间进行混合并创建过渡效果、在两种颜色之间进行插值，或混合着色器参数。

值传递节点。作用类似于全局变量，用于在 Node Graph 中传递数据。

## 节点使用说明
你添加 Named Dot 节点后，会出现两个节点。
| **节点** | **描述** |
| --- | --- |
|; | 同时用于输入和输出。 |
|; | 仅用于输出。可以输出上面的节点的输入。 |

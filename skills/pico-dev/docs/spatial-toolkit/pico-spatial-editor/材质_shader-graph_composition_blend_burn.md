一种混合操作，使用背景来使前景层变暗。计算公式为： `1 - (1 - B) / F`。

## 参数说明

* **Foreground**：前景输入。在公式中记作 `F`。
* **Background**：背景输入。在公式中记作 `B`。
* **Mix**：混合效果的权重。**Mix** 值越高，混合操作的强度越大，视觉上的效果也越明显。默认值为 `1`。超出 `0`到 `1`范围的取值会产生超出该节点预期功能范围之外的未定义效果。

## 节点使用说明
**Burn** 节点会根据前景中对应区域的暗度，对背景中的各个区域进行加深。
下面的 Shader Graph 使用 **Noise 2D** 节点生成 Perlin 噪声，并将该纹理输出连接到 **Burn** 节点的 **Foreground** 输入端。这样即可对背景砖块纹理进行压暗。

<strong>Mix</strong> = 0 情况下的压暗效果

<strong>Mix</strong> = 0.3 情况下的压暗效果

MaterialX 版本的 USD 预览表面。
**Preview Surface** 节点会根据其输入参数生成一个自定义表面。你需要将 **Preview Surface** 节点的输出连接到 **output** 节点的 **Surface** 输出端口。

## 参数说明

* **Diffuse Color**：表面的基础显示颜色。也就是物体在纯白光照下呈现的颜色。
* **Emissive Color**：表面的自发光颜色。也就是表面看起来像是自行发光时显示的颜色。
* **Use Specular Workflow：**用于指定该材质是否使用镜面反射工作流（Specular Workflow）。启用后，材质的反射属性将按照镜面反射模型来解释，而不是通过金属度模型来控制。
   * **0**：使用 Metallic 工作流。
   * **1** ：使用镜面反射工作流。
* **Metallic**：用于指示表面是否为金属。默认值为 0.0。
   * **1**：金属表面。
   * **0**：非金属表面。
* **Roughness**：表面的粗糙度。该值范围为 0 到 1.0。默认值为 0.5。
   * **0**：完全镜面反射的表面。
   * **1.0**：最大粗糙度。
* **Clearcoat**：表面上的第二层透明反射层。该属性可产生高光亮面效果。默认值为 0.0。
* **Clearcoat Roughness**：表面清漆层的粗糙度；默认值为 0.01。
* **Opacity**：表面的不透明程度。默认值为 1.0。
   * 当该值为 1.0 时，表面完全不透明
   * 当该值小于 1.0 时，表面呈现半透明效果
   * 当该值为 0 时，表面完全透明
* **Ior**：当表面为半透明或镜面时，节点使用的折射率。折射率定义了光线穿过材质时发生弯折或折射的程度。默认值为 1.5。
* **Normal**：切线空间中的法线向量；默认值为 (0, 0, 1)。
* **Occlusion**：表面接收到的环境光遮蔽程度。该值用于模拟柔和阴影和细微明暗变化。默认值为 1.0。
   * **0.0**：表示完全遮蔽区域
   * **1.0**：表示未被遮蔽区域

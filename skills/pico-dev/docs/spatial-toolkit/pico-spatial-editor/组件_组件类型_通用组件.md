本文介绍 Spatial Editor 中的通用组件。
通用组件可以被添加到实体或从实体中删除。在 .usda 文件中，通用组件的类型为 `SpatialComponent`。这是一种由 Spatial Editor 定义的、非 USD 原生的组件类型。
## Particle
粒子组件。包括 **Emitter** 设置和 **Particles** 设置。
### Emitter
发射器设置。
| **模块** | **参数** | **说明** |
| --- | --- | --- |
| 无 | Auto Play | 控制粒子是否自动发射。默认值为是。 |
| 无 | Is Emitting | 控制粒子是否发射。默认值为是。 |
| Timing | Loop | 控制粒子是否循环发射。默认值为是。 |
|  | Emission Duration | 粒子发射的持续时间，单位为秒。 ;; * **Random Between Two Constants**：表示粒子发射的持续时间在两个常量值之间随机取值。; * **Constant**：（默认）表示粒子发射的持续时间为一个固定的常量值。默认为 1。 |
|  | Idle Duration | 设置粒子每次发射之间的间隔时间，单位为秒。 ;; * **Random Between Two Constants**：表示粒子每次发射之间的间隔时间在两个常量值之间随机取值。 ;  * **Constant**：（默认）表示粒子每次发射之间的间隔时间为一个固定的常量值。默认为 0。 |
|  | Warmup Duration | 粒子发射的预热时间，单位为秒。默认为 0。 |
| Shape | Shape Type | 发射器的可用形状，包括： ;; * **Point**：从单个点发射粒子，该点没有体积或形状。 ;  * **Sphere**：一个半径为 1 米的球体，原点位于球心。 ;  * **Plane**：（默认）一个边长为 2 米的正方形平面，原点位于平面中心。 ;  * **Box**：一个边长为 2 米的正方体，原点位于正方体中心。 ;  * **Cylinder**：一个底面半径为 1 米、高为 2 米的圆柱体，原点位于其轴线中点。 ;  * **Cone**：一个底面半径为 1 米、高为 2 米的圆锥体，原点位于其轴线中点。 ;  * **Torus**：一个环面体。其主半径（从环面中心到管道中心的距离）为 1 米，次半径（管道自身的半径）由 **Torus Inner Radius** 参数定义。原点位于环面中心。 |
|  | Radial Amount  | 在 Radial（径向）方向上的数量。不能超过 360。该参数可用于控制在相关几何体（ Sphere、Torus、Cylinder、Cone ）径向分布的元素数量。  |
|  | Torus Inner Radius | Torus 管道自身的半径（单位为米），该参数与主半径共同决定了环面体的具体形状和尺寸。  |
|  | Birth Location | 设置粒子的生成位置： ;; * **Surface**：（默认）在发射器表面生成。 ;  * **Volume**：在发射器内部生成。 ;  * **Vertices**：在发射器顶点生成。 |
|  | Birth Direction | 设置粒子发射方向的计算方式： ;; * **Normal**：（默认）沿发射器形状的法线方向发射。 ;  * **World**：沿世界坐标系的方向发射。 ;  * **Local**：沿实体自身的本地坐标系方向发射。此方向会随着实体的旋转而改变。 |
|  | Shape Size | 设置发射器的尺寸，单位为米。默认值为 (0.1, 0.1, 0.1)。 |
### Particles
粒子设置。
| **模块** | **参数** | **说明** |
| --- | --- | --- |
| Main | Main | 主粒子。 |
|  | Culling Behavior Mode | 设置当粒子移出视野后，是否继续进行模拟计算。 ;; * **Auto**：（默认）如果粒子效果设置为循环（Loop），则移出视野后停止模拟；否则，将始终模拟。 ;  * **Pause**：移出视野后，一律停止模拟。 ;  * **Always Simulate**：始终进行模拟，不受视野影响。 |
|  | Birth Rate | 设置每秒生成的粒子数量。值的类型如下： ;; * **Curve**：表示粒子生成数量随时间呈曲线变化，你可以通过编辑曲线来精确控制不同时间点的粒子生成数量。 操作步骤如下： ;     1. 单击右侧的曲线图标。 ;; 2. 在弹出的 Curve 窗口选择一种曲线形状。X 轴表示时间（秒）；Y 轴表示粒子生成数量。你可以按需手动调整曲线形状。 ;; * **Random Between Two Constants**：表示粒子生成数量在两个常量值之间随机变化，你可以分别设置这两个常量值，让粒子生成数量在它们的区间内随机确定。; * **Constant**：（默认）表示粒子生成数量为一个固定的常量值，你可以直接设置该常量。 默认为 100。 |
|  | Burst Count | 设置单次爆发时生成的粒子数量。值的类型如下： ;; * **Curve**：表示粒子生成数量随时间呈曲线变化，你可以通过编辑曲线来精确控制不同时间点的粒子生成数量。 操作步骤如下： ;     1. 单击右侧的曲线图标。 ;; 2. 在弹出的 Curve 窗口选择一种曲线形状。X 轴表示时间（秒）；Y 轴表示粒子生成数量。你可以按需手动调整曲线形状。 ;; * **Random Between Two Constants**：表示粒子生成数量在两个常量值之间随机变化，你可以分别设置这两个常量值，让粒子生成数量在它们的区间内随机确定。; * **Constant**：（默认）表示粒子生成数量为一个固定的常量值，你可以直接设置该常量。 默认为 100。 |
|  | Burst Cycles | 爆发次数。-1 表示无限次，0 表示不爆发。默认为 0。 |
|  | Burst Probability | 设置粒子单次爆发的概率。取值范围为 0 到 1，0 代表从不爆发，1 代表必然爆发。默认为 1。 |
|  | Burst Time | 设置单次爆发的持续时间，单位为秒。-1 表示无限制，0 表示不爆发。默认为 -1。 |
|  | Burst Interval | 设置每次爆发之间的间隔时间，单位为秒。默认值为 1.0，且该值必须大于或等于 0。默认为 1。 |
|  | Simulation Space | 设置粒子运动的模拟空间。 ;; * **World**：（默认）粒子在世界空间中独立运动。 ;  * **Local**：粒子是跟随其发射器移动。 |
|  | Description Space ;   | 定义了粒子物理作用（如：Motion、Attract、Noise）在哪种坐标系中进行计算。 ;; * **World**：（默认）粒子物理作用在世界坐标系中进行计算。 ;  * **Local**：粒子物理作用在局部坐标系中进行计算。 |
|  | Subparticle Spawn Mode | 子粒子发射时机： ;; * **None**：表示不发射子粒子，即没有子粒子在任何时机被发射。; * **On Update**：表示在粒子更新时发射子粒子，即每当粒子进行更新操作时，会发射子粒子。; * **On Death**：（默认）表示在粒子死亡时发射子粒子，即当粒子的生命周期结束死亡时，会发射子粒子。; * **On Birth**：表示在粒子诞生时发射子粒子，即当粒子刚生成时，会发射子粒子。  |
| Secondary | Secondary | 子粒子。子粒子是由主粒子发射出来的粒子，其发射时机可通过 **Subparticle Spawn Mode** 参数的 **None**、**On Update**、**On Death**、**On Birth** 等模式进行控制。  |
|  | Enable Secondary Particles | 是否启用子粒子。默认不启用。 |
|  | Culling Behavior Mode | 详情参见 Main 模块的 **Culling Behavior Mode** 参数描述。 |
|  | Burst Count | 详情参见 Main 模块的 **Burst Count** 参数描述。 |
|  | Simulation Space | 详情参见 Main 模块的 **Simulation Space** 参数描述。 |
|  | Description Space | 详情参见 Main 模块的 **Description Space** 参数描述。 |
| General Settings ;   | Life Time | 粒子寿命（秒）。值的类型如下： ;; * **Curve**：表示粒子寿命随时间呈现曲线变化，你可以通过设置曲线的形状和参数来精确控制粒子在不同时间点的寿命情况。 操作步骤如下： ;     1. 单击右侧的曲线图标。 ;; 2. 在弹出的 Curve 窗口选择一种曲线形状。X 轴表示时间（秒）；Y 轴表示粒子寿命。你可以按需手动调整曲线形状。 ;; * **Random Between Two Constants**：表示粒子寿命在两个常量值之间随机变化，你可以分别设置这两个常量值，让粒子寿命在它们的区间内随机确定。 ;  * **Constant**：（默认）表示粒子寿命为一个固定的常量值。 默认为 1。 |
|  | Start Speed | 该参数定义了粒子的初始速度（单位：米/秒），具体含义取决于粒子类型： ;; * **主粒子：** 指其发射速度。 ;  * **子粒子：** 指其自身的发射速度。子粒子的最终速度是该值与继承的父粒子速度之和。 ;; 该参数值的类型如下： ;; * **Curve**：表示初始速度随时间呈曲线变化，你可以通过编辑曲线来精确控制不同时间点的初始速度。 操作步骤如下： ;     1. 单击右侧的曲线图标。 ;; 2. 在弹出的 Curve 窗口选择一种曲线形状。X 轴表示时间（秒）；Y 轴表示粒子的初始速度。你可以按需手动调整曲线形状。 ;; * **Random Between Two Constants**：表示初始速度在两个常量值之间随机变化，你可以分别设置这两个常量值，让初始速度在它们的区间内随机确定。 ;  * **Constant**：（默认）表示初始速度为一个固定的常量值，你可以直接设置该常量。  默认为 0.5。 |
|  | Velocity Inherit Ratio | 子粒子继承其父粒子速度的比例。0 表示不继承，1 表示完全继承，大于 1 表示在继承父粒子速度的基础上额外增加一定倍数的速度。默认为 0。 |
|  | Inherit Color | 设置子粒子是否继承其父粒子的颜色。 默认为否。 |
|  | Mass ;   | 粒子的质量，单位为克。该值会影响粒子的运动，具体表现为惯性。 ;  该参数值的类型如下： ;; * **Random Between Two Constants**：表示粒子质量在两个常量值之间随机变化，你可以分别设置这两个常量值，让粒子质量在它们的区间内随机确定。 ;  * **Constant**：（默认）表示粒子质量为一个固定的常量值，你可以直接设置该常量。默认为 1。 |
|  | Start Size | 设置粒子的初始大小（单位：米）。 ;  该参数值的类型如下： ;; * **Curve**：表示粒子大小随时间呈曲线变化，你可以通过编辑曲线来精确控制不同时间点的粒子大小。 操作步骤如下： ;     1. 单击右侧的曲线图标。 ;; 2. 在弹出的 Curve 窗口选择一种曲线形状。X 轴表示时间（秒）；Y 轴表示粒子大小。你可以按需手动调整曲线形状。 ;; * **Random Between Two Constants**：表示粒子大小在两个常量值之间随机变化，你可以分别设置这两个常量值，让粒子大小在它们的区间内随机确定。 ;  * **Constant**：表示粒子大小为一个固定的常量值，你可以直接设置该常量。默认为 0.02。 |
|  | Enable Size over Life | 是否启用粒子生命周期内的大小变化。 |
|  | Separate Axes  | 是否对 X、Y、Z 轴分别设置粒子大小。该参数仅在 **Enable Size over Life**  参数被启用后才会显示。 |
|  | Size | 粒子的大小。该参数仅在 **Enable Size over Life**  参数被启用后才会显示。 |
|  | Enable Size Modifier  | 是否启用粒子大小调整。启用后，将显示 **End Size Ratio** 参数和 **Size Lerp Factor** 参数。默认不启用。 |
|  | End Size Ratio ;   | 定义了粒子在生命周期结束时，相对于其初始大小的尺寸比例。该参数仅在 **Enable Size Modifier**  参数被启用后才会显示。默认为 0.1。 |
|  | Size Lerp Factor | 控制粒子大小在其生命周期内的变化速率。该参数仅在 **Enable Size Modifier**  参数被启用后才会显示。 ;; * **1**：（默认）大小呈线性变化。 ;  * **小于 1**：大小在生命周期初期变化较快。 ;  * **大于 1**：大小在生命周期初期变化较慢。 |

|  | Enable Rotation over Life | 启用随生命周期变化的旋转。打开后，粒子的朝向会在其存活期间按设定值变化。 |

|  | Enable Rotation Velocity over Life | 启用随生命周期变化的旋转速度。 |
|  | Separate Axes | 是否对 X、Y、Z 轴分别设置粒子旋转速度。该参数仅在 **Enable Rotation Velocity over Life**  参数被启用后才会显示。 |
|  | Rotation | 粒子在生命周期内绕对应轴的角速度。 |
|  | Max Particle Count | 单个粒子系统中活跃粒子的数量上限。默认值为 256。 |
| Color | Start Color | 设置粒子的初始颜色。默认为白色。 |
|  | Enable Color Gradient over Life | 启用生命周期颜色渐变。 |

## Draw Order

此组件用于精确控制实体的渲染顺序。
在复杂的 3D 场景中，当多个 **半透明** 物体发生重叠或需要明确前景与背景的遮挡关系时，可能会出现深度排序冲突（Z-fighting），导致渲染效果不符合预期。你可以通过 Draw Order 组件控制实体的渲染顺序。
| **参数** | **说明** |
| --- | --- |
| Group | 绘制排序组（Draw Order Group）。所有具有相同 **Group** 的实体都属于一个绘制排序组。你可以在 Inspector 窗口添加一个或多个绘制排序组。详情参阅 [在绘制排序组中调节实体渲染顺序](/editor/general-components)。 |
### 在绘制排序组中调节实体渲染顺序
参考以下步骤添加一个绘制排序组，将其关联到实体的 Draw Order 组件，然后在绘制排序组中调节实体渲染顺序。
假设场景中包括一个半透明的绿色球体和一个半透明的红色平面。在默认的渲染顺序下，红色平面会遮挡位于其后方的绿色球体部分。

1. 在 **Hierarchy** 窗口，点击 **+** 号，在下拉菜单中选择 **Draw Order Group** 创建一个绘制排序组。

2. 把实体关联到绘制排序组。你可以使用以下任意一种方式：
   * 选中 Hierarchy 窗口的绘制排序组**，然后**把需要关联绘制排序组的实体从 **Hierarchy** 窗口拖拽到 **Inspector** 窗口中的绘制排序组。

   * 选中需要关联绘制排序组的实体，在 **Inspector** 窗口中找到 **Draw Order** 组件，点击  **Group** 参数后的选择按钮，然后从列表中选择刚刚创建的绘制排序组。

3. 在 **Hierarchy** 窗口选中绘制排序组，在 **Inspector** 窗口通过拖拽调节实体的渲染顺序。列表上方的实体渲染顺序更靠前，即渲染优先级更高，会先于列表下方的实体进行渲染。

例如，如果绿色球体的渲染优先级更高，它会被绘制在红色平面之上，无视两者实际的远近关系。尽管红色平面在物理上更靠近相机，但绿球会渲染在红色平面的前面。

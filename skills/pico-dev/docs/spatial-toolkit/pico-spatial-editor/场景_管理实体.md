本文介绍如何在视图窗口管理实体（Entity），涵盖添加、选择、移动、旋转、缩放等操作。
## 添加实体
你可以从 **Project Browser** 窗口中把资源拖拽到视图窗口中。视图窗口会显示该资源。资源默认会被添加为 Root 节点的子节点。

## 选中实体
如果你要选中实体，视图窗口左侧工具栏必须被设置为 **Move the selected object**、**Rotate the selected object** 或 **Scale the selected object。**

你可以通过以下方式选中一个或多个实体：

* **选中单个实体**：在视图窗口中单击目标实体。

* **逐个加选多个实体**：按住 Ctrl 键 (Windows) 或 Command 键 (macOS)，然后依次单击目标实体。再次单击已选中的实体可以取消加选。

* **框选多个实体**：在视图窗口中拖动鼠标，框选所有目标实体。

## 聚焦到选中的实体
选中实体后，按 F 键。

## 删除实体
选中实体后，你可以按 Delete 键 (Windows) 或 Backspace 键 (macOS) 删除实体。

## 移动实体
如果你要移动实体，视图窗口左侧工具栏必须被设置为 **Move the selected object。**

选中实体后，你可以通过鼠标沿着方向轴移动实体。
* 坐标轴的颜色分别代表：
   * 红色： X 轴。
   * 绿色： Y 轴。
   * 蓝色： Z 轴。
* 拖动彩色的正方形图标，可以在一个平面上移动实体。各颜色对应的平面如下：
   * 蓝色：XY 平面
   * 红色：YZ 平面
   * 绿色：XZ 平面
* 按住 Shift 键并移动实体，可以使其以 1 厘米为单位进行移动。

## 旋转实体
如果你要旋转实体，视图窗口左侧工具栏必须被设置为 **Rotate the selected object。**

选中实体后，你可以拖动圆环来修改实体的角度。
你可以通过拖动不同的控制环来旋转实体：

* 拖动 **红色**、**绿色** 和 **蓝色** 的圆环，可以分别绕 X、Y、Z 轴旋转。
* 拖动 **中间的灰色圆球**，可以进行任意角度的自由旋转。
* 拖动 **外侧的灰色圆环**，可以绕着垂直于你当前视角的轴向旋转。
* 旋转时按住 `Shift` 键，实体会以 5° 为增量进行旋转。

## 缩放实体
如果你要缩放实体，视图窗口左侧工具栏必须被设置为 **Scale the selected object。**

选中实体后，你可以通过拖动方向轴来修改实体的大小。
你可以按以下方式缩放实体：

* 单轴缩放：拖动不同颜色的控制轴，可以沿单个轴向进行缩放。
   * 红色：沿 X 轴缩放。
   * 绿色：沿 Y 轴缩放。
   * 蓝色：沿 Z 轴缩放。
* 等比缩放：拖动中心的灰色方块，可以等比缩放整个实体。

此外，如果你在实体的 Transform 组件中锁定了 **Scale** 属性，那么拖动任意颜色的控制轴都将变为等比缩放。

## 预览实体在空间容器中的显示效果
你可以在视图窗口中添加空间容器，以预览实体在其中的显示效果。
Spatial Editor 提供的显示效果仅供预览。在你的空间应用中，你需要通过 PICO Spatial SDK 将实体添加到空间容器。详情参阅 [了解空间容器 & 空间状态](/spatial-sdk/learn-about-spatial-containers-and-space-states/)。

1. 在视图窗口顶部的工具栏，单击 **Spatial Container** 右侧的下拉箭头。

2. 选择一种空间容器。你可以按需设置空间容器的参数。
   | **空间容器** | **描述** | **参数** |
   | --- | --- | --- |
   | Planar | Planar 窗口是一种形似“平面面板”的 WindowContainer，其厚度固定。特点如下： ;; * 你只能修改其长度（X 轴）和宽度（Y 轴），其高度（Z 轴）是固定的。 ;  * 其中心点与场景的世界坐标原点 (0, 0, 0) 对齐。 ;  * 渲染时，模型超出容器边界的部分将被裁切。 | * **Unit**：长度单位。 ;     * Meter：米。; * dp：设备像素（Device Pixels）。 ;  * **Size**：尺寸。默认为 1280*720*640 dp。最小为 320*180*640 dp，最大为 2700*1800*640 dp。 ;  * **UI Sample**：是否展示示例 UI 组件。 |
   | Volumetric | Volumetric 窗口是一种尺寸可调的“长方体” WindowContainer，具有以下特点： ;; * 你可以修改其在 X、Y、Z 轴上的尺寸。 ;  * 其中心点与场景的世界坐标原点 (0, 0, 0) 对齐。 ;  * 渲染时，模型超出容器边界的部分将被裁切。 | * **Unit**：长度单位。 ;     * Meter：米。; * dp：设备像素（Device Pixels）。 ;  * **Size**：尺寸。默认为 960*960*960 dp。最小为 320*320*320 dp，最大为 2700*2700*2700 dp。 ;  * **UI Sample**：是否展示示例 UI 组件。 |
   | Stage | 一个无边界的虚拟舞台，具有以下特点： ;; * 不限制模型的尺寸。 ;  * 其原点 (0, 0, 0) 默认位于玩家脚下，与 Viewport 的原点保持一致。 | 无 |

用于基于物理渲染 (PBR) 材质的表面着色器。
**PBR Surface** 节点会根据其输入参数生成一个自定义表面。你需要将 **PBR Surface** 节点的输出连接到 **output** 节点的 **Surface** 输出端口。

## 参数说明

* **Base Color**：表面的基础显示颜色。也就是物体在纯白光照下呈现的颜色。
* **Opacity**：表面的不透明程度。默认值为 1.0。
   * 当该值为 **1.0** 时，表面完全不透明
   * 当该值小于 **1.0** 时，表面呈现半透明效果
   * 当该值为 **0** 时，表面完全透明
* **Metallic**：指示表面是否为金属。默认值为 0.0。
   * **1**：金属表面
   * **0**：非金属表面
* **Roughness**：表面的粗糙度。该值范围为 0 到 1.0。默认值为 0.5。
   * **0**：完全镜面反射的表面
   * **1.0**：最大粗糙度
* **Normal**：切线空间中的法线向量。默认值为 (0,0,1)。
* **Clearcoat**：表面上的第二层透明反射层。该属性可产生高光亮面效果。默认值为 0.0。
* **Clearcoat Normal**：切线空间中清漆层的法线向量。默认值为 (0,0,1)。
* **Clearcoat Roughness**：表面清漆层的粗糙度。默认值为 0.01。
* **Emissive**：表面的自发光颜色。也就是表面看起来像是自身发光时显示的颜色。
* **Ambient Occlusion**：表面接收到的环境光照程度。该值用于模拟柔和阴影和细微的明暗变化。
* **Reflectance**：表面的反射率，即表面反射光线的能力。默认值为 0.5。
* **Anisotropy Level**：表面各向异性的程度，用于控制表面在不同方向上的反射特性，默认值为 0.0。
* **Anisotropy Direction**：表面各向异性的方向，用于指定表面反射特性在不同方向上的具体指向，默认值为 (0,0,0)。

PICO Spatial Plugin 是一款基于 Android Studio 的一站式空间应用开发插件，可为开发者提供完整的空间应用开发工具链。
PICO Spatial Plugin 支持以下功能：

* **空间应用模板**：在 Android Studio 中提供空间应用的模板。你可以基于模板快速创建 Spatial 项目。详情参阅 [管理 Spatial 项目](./spatial-toolkit_pico-spatial-plugin_管理-spatial-项目.md)。
* **构建 Spatial 项目**：把 Spatial 项目构建为空间应用。详情参阅 [管理 Spatial 项目](./spatial-toolkit_pico-spatial-plugin_管理-spatial-项目.md)。
* **管理空间应用开发工具**：安装、升级或卸载 PICO Emulator（模拟器）和 PICO Spatial Editor（Spatial Editor）。详情参阅 [管理空间应用开发工具](/manage-pico-toolbox)。
* **把空间应用连接到 Spatial Editor**：你可以把 Spatial Editor 项目导入到 Spatial 项目，从而在 Android Studio 和 Spatial Editor 中同步管理 3D 资源和自定义组件。详情参阅 [管理 Spatial 项目](./spatial-toolkit_pico-spatial-plugin_管理-spatial-项目.md)、[管理资源](/manage-resource) 和 [管理自定义组件](/use-custom-components)。

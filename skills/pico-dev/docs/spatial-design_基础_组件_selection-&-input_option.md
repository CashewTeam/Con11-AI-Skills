Option 将预设的可选项以结构化形式呈现，帮助用户快速做出决策。每个 Option 是独立的选择单元，代表一个具体的可选项，与其他 Option 可能存在互斥（单选）或并列（多选）关系。

## 构成
为了清晰传递自身含义，通常通过文本、图标、辅助说明等元素让用户理解选项内容及差异。

1. 容器：高度 48 dp，高宽度随内容自适应。
2. 文本区域：选项的核心标识，通常是简短的关键词或短语，直接表达选项含义。建简洁明了，避免因过长影响可读性。
3. 图标：加上图标强化选项的辨识度，尤其适合抽象概念或需要快速区分的场景。
4. 复选框：带上复选框能突出强调已被选中的状态。

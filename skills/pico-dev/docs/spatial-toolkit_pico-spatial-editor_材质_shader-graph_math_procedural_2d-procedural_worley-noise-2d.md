2D Worley 噪声生成器。

## **参数说明**

* **texcoord**：用于读取数据以将纹理映射到表面的二维坐标。默认使用当前 **UV** 坐标，其中 **U** 为水平轴，**V** 为垂直轴。
* **Jitter**：每个单元中心发生抖动或偏移的程度。默认值为 1.0。较小的值会生成更规则的图案，而 0 会生成完美的方形。

## **节点使用说明**
**Worley Noise 2D** 节点以程序化方式生成不均匀的细胞状区域。它会创建有限数量的中心点，每个区域都是围绕某个中心点形成的多边形，并由距离该中心点最近的位置构成。
下图展示了使用 **Worley Noise 2D** 节点程序化生成黑白图案的示例。将输入的纹理坐标与一个常量浮点值相乘，可以改变生成噪声的频率。数值越大，图案重复得越频繁。然后再将输出传入一个转换节点，将其变为黑白颜色值。

本文介绍如何在 Spatial Editor 中管理组件。
## 什么是组件
组件（Component）是一组有特定格式的数据，为实体（Entity）赋予特定的功能和属性。

* 在 Spatial Editor 中，不同类型的实体被内置了不同的组件。 另外，你也可以为实体添加其他内置组件或自定义组件，以满足特定需求并进一步扩展实体的功能。
* 在 PICO Spatial SDK 中，`Component` 表示与 `Entity` 相关的、具有特定格式的数据。内置的 `Component` 包括 3D 模型组件、空间变换组件、渲染组件、物理组件、动画组件等。除此之外，你还可以创建自定义 `Component`，用于存储特定功能的数据，从而扩展系统能力。

## 添加组件
选中一个实体后，点击 **Inspector** 窗口底部的 **Add Component** 按钮，即可查看所有可添加的组件。

## 删除组件
选中一个实体后，在 **Inspector** 窗口中找到要删除的组件，点击其右侧的 **···**，然后选择 **Delete** 即可删除该组件。

## 复制组件参数
选中一个实体后，在 **Inspector** 窗口中找到要删除的组件，点击其右侧的 **···**，然后选择 **Copy Component** 即可完成组件参数配置的复制。

## 粘贴组件参数
选中一个实体后，在 **Inspector** 窗口中找到要删除的组件，点击其右侧的 **···**，然后选择 **Paste Component** 即可将之前复制的组件参数粘贴到该组件，实现参数的覆盖操作。

## 撤销组件参数修改
选中一个实体后，在 **Inspector** 窗口中找到要删除的组件，点击其右侧的 **···**，然后选择 **Remove Overrides** 即可撤销对该组件参数所做的所有修改，使其恢复至默认值或继承值。

## 其他操作
点击 **Inspector** 窗口右上角的 **···**，会展开一个下拉菜单。每个选项的说明如下：
| **选项** | **说明** |
| --- | --- |
| **Copy Object Path** | 复制实体在场景中的相对路径。 |
| **Copy Components** | 复制实体的所有组件。 |
| **Paste Components** | 粘贴实体的所有组件。 |
| **Deactivate/Activate** | 禁用或启用实体。禁用后，该实体会被从场景中移除，但你可随时重新启用将其恢复到场景中。 |
| **Disable/Enable** | 隐藏或显示实体。隐藏后，该实体将无法被渲染，也无法与物理系统交互。 |
| **Lock/Unlock** | 锁定或解锁实体。锁定后，该实体将不接受任何修改。 |
| **Remove Overrides** | 撤销对所有组件参数的修改。 |

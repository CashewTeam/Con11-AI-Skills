Select Field 常用于创建下拉选择框，允许用户从预定义的选项列表中选择一个或多个值的组件，通常会有一个下拉框，里面有多个选项供用户选择，用户也可以自行输入。

## 构成

1. 可见的交互入口，通常包含当前选中项，未选择时显示，显示占位提示，如 “请选择城市”。
2. 交互按钮：下拉按钮，用户点击后会展开一个选项列表。

## 交互行为

1. **展开与折叠**
   * 当用户获取焦点时，自动展开 Option Menu。Option Menu 只是提供快捷选择或推荐内容，用户可以自行输入。
   * 选择选项后自动折叠：单选模式下，点击选项后列表自动收起；多选模式下通常不自动折叠，需用户手动确认。
   * 点击外部区域：展开状态下，点击页面其他空白处，列表自动折叠。
2. **展开方向**
   列表与选择字段（Select Field）右对齐，列表宽度不超过选择字段，列表长度可根据内容自行设定，若内容过多，可采用固定长度并设置滚动功能 。
3. **筛选**
   列表展开时，输入文字可实时筛选选项（如输入 “运” 显示 “运动中心”），提升选择效率。
4. **选中反馈**
   * 选项旁显示勾选图标（✓）。
   * 触发区域实时更新为选中项内容，例如：从 “请选择” 变为 “运动中心（当前应用）”。
5. **状态反馈**
   * 聚焦时：触发区域显示高亮样式。
   * 悬停时：选项列表中当前鼠标指向的选项显示 hover 样式（背景变化）。
   * 禁用时（disabled）：触发区域灰显，无法点击或聚焦，鼠标悬停无反馈。

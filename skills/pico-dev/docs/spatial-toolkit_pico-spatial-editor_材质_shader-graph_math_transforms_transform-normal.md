将法线从一个空间转换到另一个空间。

## 参数说明

* **In：**要进行变换的法线向量。
* **From Space：**输入向量 **In** 所在的源空间。默认为 **world**。可使用的有效空间值如下：
   * **model**：相对于模型的局部坐标空间。
   * **object**：相对于对象的坐标空间。
   * **world**：相对于整个世界的全局坐标空间。
* **To Space**：输入向量 **In** 要变换到的目标空间。默认为 **world**。可使用的有效空间值如下：
   * **model**：相对于模型的局部坐标空间。
   * **object**：相对于对象的坐标空间。
   * **world**：相对于整个世界的全局坐标空间。

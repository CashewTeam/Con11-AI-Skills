切换开关是一种能够在两种模式（即开启和关闭）之间进行切换的开关。依据不同事件，切换开关可为用户预设开启或关闭状态。通常情况下，切换开关用于设置控件。

## 构成
通常切换按钮通常独立存在，不带文字。

1. **开关轨道：**
   开关轨道为圆角矩形条，是开关的基础承载结构；通过颜色或样式变化直观体现整体状态（开启 / 关闭）。
2. **开关滑块：**
   圆形或圆角矩形的可移动部件，位于轨道之上。通过位置变化强化状态感知，是交互的核心触发点。

## 交互行为

* **交互方式：**
   用户点击开关的轨道（Track）或滑块（Thumb），直接切换 “开启”（On）和 “关闭”（Off）状态（一般无需二次确认，但也会有特殊需求需要二次确认）。
* **操作热区：**
   操作热区尺寸为 40 * 36 dp
* **视觉反馈**
   * 状态颜色差异：
      * 开启时：轨道显示高亮色（蓝色），滑块移至激活侧（右侧）
      * 关闭时：轨道显示（灰色），滑块移至非激活侧（左侧）
      * 禁用时：整体灰度化（ 30% 透明度），点击 / 滑动无响应，明确不可操作
   * 滑块位置同步：滑块始终随状态精准定位

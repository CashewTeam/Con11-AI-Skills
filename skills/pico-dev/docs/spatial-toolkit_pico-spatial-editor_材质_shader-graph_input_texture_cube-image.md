生成并配置立方体纹理。

## 参数说明

* **File**：用于该纹理的图像文件。支持 .png、.jpg/.jpeg、.bmp、.tga、.hdr 和 .exr 格式的贴图。
   你需要确保贴图的 **Texture Format** 是 **Cube**。你可以在 **Project Browser** 窗口中选中贴图，然后在右侧窗口中查看贴图的 **Texture Format**。若 **Texture Format** 不是 **Cube**，你可以将其修改为 **Cube，**然后点击 **Apply。**

* **U Wrap Mode**：指定节点如何处理超出 0–1 范围的 **U** 值。默认值为 **clamp_to_edge**。
* **V Wrap Mode**：指定节点如何处理超出 0–1 范围的 **V** 值。默认值为 **clamp_to_edge**。
* **Border Color**：用于填充材质表面上未被材质属性图像内容覆盖区域的颜色。默认值为 **transparent_black**。
* **Mag Filter**：当图像内容以大于原始图像尺寸进行渲染时，节点使用的放大过滤模式。例如，靠近相机的某个点，其纹理坐标可能只对应纹理图像中不到一个像素的小区域。此时节点使用 **Mag Filter** 来决定该点采样得到的纹素颜色。默认值为 **linear**。
* **Min Filter**：当图像内容以小于原始图像尺寸进行渲染时，节点使用的缩小过滤模式。例如，远离相机的某个点，其纹理坐标可能对应纹理图像中多个像素组成的区域。此时节点使用 **Min Filter** 来决定该点采样得到的纹素颜色。默认值为 **linear**。
* **Mip Filter**：当使用 mipmapping 渲染图像内容时，节点使用的 mipmap 过滤模式。当图像以小于原始图像尺寸渲染时，这个参数尤其有用。如果该参数值为 **None**，节点将不使用 mipmapping。默认值为 **linear**。
* **Max Anisotropy**：渲染纹理图像内容时应用的各向异性过滤强度。当图像内容相对于相机以较大倾斜角度显示时会使用该参数。该参数仅应与 mipmapping 一同使用，因此只有当 **Mip Filter** 不为 **None** 时它才会生效。默认值为 **1**。
* **Max LOD Clamp**：渲染图像内容时允许的最大细节层级。当对象靠近相机时，用于渲染该对象纹理的细节层级会提高，最高不超过该参数定义的最大值。默认值为 **65504**。
* **Min LOD Clamp**：渲染图像内容时允许的最小细节层级。当对象远离相机时，用于渲染该对象纹理的细节层级会降低，最低不低于该参数定义的最小值。默认值为 **0**。
* **Texture Coordinates**：用于读取数据并将纹理映射到表面的 2D 坐标。默认值为当前的 UV 坐标，其中 **U** 表示水平方向，**V** 表示垂直方向。
* **Bias**：渲染图像内容时细节层级（LOD）的偏置值。当渲染后的纹理尺寸介于两个 LOD（Level of Detail）层级之间时，该参数会影响渲染器更倾向于选择较高细节层级还是较低细节层级。当该值介于 **0 和 1** 之间时，节点更倾向于使用**较低细节**；当该值 **大于 1** 时，节点更倾向于使用较高细节。默认值为 **0**。
* **Dynamic Min Lod Clamp**：渲染图像内容时允许的最小细节层级。与 **Min Lod Clamp** 参数类似，但该参数可以在运行时动态修改。

## 节点使用说明
### Wrap Mode 参数的可选值

* **clamp_to_border**：边界钳制。节点会将超出正常范围的纹理坐标设置为 **Border Color** 参数指定的颜色。
* **clamp_to_edge**：边缘钳制。节点会将超出正常范围的纹理坐标钳制到正常范围内。也就是说，大于 1 的值会被设为 1，小于 0 的值会被设为 0。这意味着图像边缘处的颜色会向外延展，填充纹理剩余区域。
* **mirrored_clamp_to_edge**：镜像边缘钳制。节点会对超出正常范围的纹理坐标执行镜像边缘钳制。超出范围的部分不会被循环重复，而是按照边界方向进行镜像延展，并最终限制在边缘区域内，因此图像边缘会以更连续的镜像方式向外扩展。
* **mirrored_repeat**：节点会对超出正常范围的纹理坐标进行镜像重复。
* **repeat**：节点会让超出正常范围的纹理坐标“循环回绕”。这种行为等价于对坐标执行模 1 运算。

### Mag Filter 和 Min Filter 的可选值

* **linear**：过滤器使用邻近值的线性插值来确定最终渲染内容。
* **nearest**：过滤器使用最近邻值来确定最终渲染内容。

### Mip Filter 的可选值
**Mip Filter** 参数具有与 **Mag Filter** 和 **Min Filter** 相同的可选值，另外还增加了 **None** 选项，表示不使用 mipmapping。

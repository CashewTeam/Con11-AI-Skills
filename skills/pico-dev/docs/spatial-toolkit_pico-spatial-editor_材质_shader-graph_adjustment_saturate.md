调节颜色的饱和度。

## 参数说明

* **In**: 待调节饱和度的输入颜色。
* **Amount**：用于调节饱和度的乘数，默认值为 `1.0`。
* **Luma Coefficients**: 定义了计算亮度时所依据的颜色空间的权重系数。不同的颜色空间对 R、G、B 三个通道的贡献度有不同的定义。可选的值为 **acescg**、**rec2020/rec2100** 或 **rec709** 颜色空间的亮度系数。默认值为 **acescg** 的亮度系数，即 `(0.2722287, 0.6740818, 0.0536895)`。

## 节点使用说明
**Saturate** 节点在输入颜色值和该颜色的亮度值之间进行线性插值。

* 当 **Amount** 参数值为 `0` 时，输出结果为输入的灰度版本，等同于 **Luminance** 节点的输出。
* 当 **Amount** 参数值为 `1` 时，输出原始颜色。

此节点的效果与使用 **HSVAdjust** 节点调节饱和度不同。**Saturate** 节点在处理修改时会考虑颜色空间。

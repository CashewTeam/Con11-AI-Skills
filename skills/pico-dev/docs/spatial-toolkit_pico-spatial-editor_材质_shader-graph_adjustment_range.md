将一个范围内的输入值重新映射到另一个范围。还提供了 Gamma 校正和限制（Clamp）输出的选项。

## 参数说明

* **In**: 需要重新映射的原始输入值。
* **In Low**: 定义了输入值范围的起始点。
* **In High**: 定义了输入值范围的结束点。
* **Gamma**：控制施加于输入值的反指数。节点会先将输入范围映射到 `0..1` 区间，然后再应用该反指数。默认值为 `1.0`。
* **Out Low**: 定义了输出值范围的起始点。
* **Out High**: 定义了输出值范围的结束点。
* **Do Clamp**：控制是否对输出值进行限制。
   * **true**：输出会被限制在 **Out Low** 和 **Out High** 参数定义的范围内。
   * **false**：（默认）输出不会被限制在 **Out Low** 和 **Out High** 参数定义的范围内。

## 节点使用说明
**Range** 节点用于将输入值从一个范围重新映射到另一个范围。节点还支持在映射过程中应用 Gamma 校正，该校正发生在转换过程的中间阶段。**Gamma** 值表示施加于输入值的反指数。例如，**Gamma** = 2 时，输入值会被计算为其 1/2 次幂，即相当于求平方根。节点还支持对输出结果进行钳制。启用该选项后，小于 **Out Low** 的输出值将被设为 **Out Low**，大于 **Out High** 的输出值将被设为 **Out High**。

本文介绍 Spatial Editor 支持的着色器类型。
## 内置着色器
Spatial Editor 内置的着色器类型包括 Physically Based、Unlit 和 Cloth。下图从左到右依次展示了 Physically Based、Unlit 和 Cloth 这三种着色器的视觉效果。详情参阅 [材质参数说明](/editor/manage-material)。

## 自定义着色器
在 Shader Graph 中，你可以通过创建和连接节点的方式创建自定义着色器。详情参阅 [什么是 Shader Graph](./spatial-toolkit_pico-spatial-editor_材质_shader-graph_什么是-shader-graph.md)。

欢迎来到 PICO Spatial SDK 的《从模板开始搭建空间应用》系列教程。
本系列教程将帮助你系统掌握使用 PICO Spatial SDK 搭建空间应用的方法。你将从一个 Planar Window Container 模板项目出发，遵循“平面窗口 → 立体窗口 → 沉浸式场景”的学习路径，逐步将传统的 2D/2.5D 应用扩展为空间应用，整合 3D 内容、空间交互与动画效果。
完成整个系列教程后，你将能够：

* 理解 PICO 空间应用的基本结构、启动流程，以及 Window Container 与 Stage 的核心差异。
* 在 Planar Window Container 中组织 2D 与 3D 内容，并实现窗口间的打开与关闭。
* 创建 Volumetric Window Container，在其中放置、变换和操控 3D 模型。
* 使用 Stage 将应用扩展到 Full Space，构建沉浸式场景，并为 3D 模型添加轨道动画和控制面板。

本系列教程包含以下三个阶段：

* [第一阶段：从平面窗口和 2D 内容开始](./spatial-tutorial_从模板开始搭建空间应用_第一阶段：从平面窗口和-2d-内容开始.md)
   你将从 Planar Window Container 模板项目入手，理解模板结构、默认窗口声明方式，以及如何在主窗口中组合 2D UI、2.5D 效果和基础 3D 内容。
* [第二阶段：加入 3D 窗口和模型](./spatial-tutorial_从模板开始搭建空间应用_第二阶段：加入-3d-窗口和模型.md)
   你将进一步创建 Volumetric Window Container，学习如何声明具有体积感的窗口，并通过代码创建、旋转和拖拽一个 3D 模型。
* [第三阶段：扩展到沉浸式场景](./spatial-tutorial_从模板开始搭建空间应用_第三阶段：扩展到沉浸式场景.md)
   你将把应用从 Shared Space 扩展到 Full Space，创建 Stage，配置天空球与环境光照，并实现一个结合 3D 轨道动画与 2D UI 的沉浸式场景。

为了获得更好的学习效果，建议你按照教程顺序依次实践。每一步都会在前一步的基础上继续扩展，因此完成整个系列教程后，你不仅能充分理解空间应用的关键概念，也能使用 PICO Spatial SDK 构建一个自己的空间应用。

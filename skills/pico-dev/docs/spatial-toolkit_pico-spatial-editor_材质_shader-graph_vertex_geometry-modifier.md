根据输入参数修改几何体的顶点属性，并对每个顶点执行一次。
你需要将其连接到 **output** 节点的 **Geometry Modifier** 端口。
该节点生成的着色器会在顶点着色器中执行，因此所有从该节点的输入端口连接出去的节点（包括间接连接的节点）所生成的着色器，也都会在顶点着色器中执行。

## 参数说明

* **Model Position Offset**：模型位置偏移量。用于沿模型空间中的方向偏移几何体顶点位置。
* **Color**：颜色属性。用于为几何体提供颜色数据，通常可作为顶点颜色供后续着色使用。
* **Normal**：法线向量。用于定义表面的朝向，并影响光照和反射计算。
* **Tangent**：切线向量。用于定义表面的切线空间，常用于法线贴图和方向性着色计算。
* **Uv0**：第一组 UV 坐标，通常用于主纹理映射。
* **Uv1**：第二组 UV 坐标，通常用于附加纹理映射或光照贴图。
* **Uv2 ~ Uv7**：额外的 UV 或自定义数据通道，可用于存储扩展纹理坐标或其他着色数据。

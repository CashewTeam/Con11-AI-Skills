对输入流的通道执行任意排列，并返回一个指定类型的新数据流。

### 参数说明

* **In**：输入数据流。
* **Channels**：通过字符串指定输入通道如何重排以构成输出。

### 节点使用说明
**Swizzle** 节点的输出取决于 **Channels** 参数。**Channels** 字符串中的每个字符代表 **In** 参数的一个通道。例如，如果 `In` 是一个值为 `(1, 5, 10)` 的 **Vector 3 Vector 3**，则 "x" 对应 `1`，"y" 对应 `5`，"z" 对应 `10`。字符的顺序决定了输入通道如何重排以构成输出。在上述例子中，如果 **Channels** 参数为 "zzz"，则输出为 `(10, 10, 10)`。
**Channels** 字符串的长度必须等于输出通道的数量。

下表展示了 **Swizzle** 节点处理过程的更多示例：
| **Type** | **In** | **Channels** | **Out** |
| --- | --- | --- | --- |
| Vector 3 Vector 3 | (1, 5, 10) | zzz | (10, 10, 10) |
| Vector 3 Vector 3 | (1, 5, 10) | zyx | (10, 5, 1) |
| Vector 2 Vector 3 | (5, 0) | xxy | (5, 5, 0) |
| Vector 3 Vector 2 | (1, 5, 10) | zx | (10, 1) |
| Vector 3 Color 3 | (0.5, 0.8, 0) | grb | (0.8, 0.5, 0) |

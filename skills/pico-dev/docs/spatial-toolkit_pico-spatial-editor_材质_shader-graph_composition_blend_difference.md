输出前景和背景值之间的距离。计算公式为：`abs(B −F)`。

## **参数说明**

* **Foreground**：前景输入，在公式中记作 `F`。
* **Background**：背景输入，在公式中记作 `B`。
* **Mix**：混合效果的权重。`Mix` 值越高，混合运算的强度越大，视觉效果也越明显。默认值为 `1`。当取值超出 `0` 到 `1` 范围时，会产生超出该节点预期功能之外的未定义效果。

### **节点使用说明**
**Difference** 节点会对两个输入执行相减运算，并取结果的绝对值。
**Difference** 节点通过 **Mix** 输入控制前景在混合中的权重。**Mix** 值越接近 `1`，输出的差异效果越强；越接近 `0`，该效果越弱。

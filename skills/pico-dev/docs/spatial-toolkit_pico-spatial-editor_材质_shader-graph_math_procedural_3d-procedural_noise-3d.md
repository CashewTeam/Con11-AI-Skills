3D Perlin 噪声生成器。

## 参数说明

* **Amplitude**：生成噪声的强度。振幅越高，噪声图案中的变化就越明显。
* **Pivot**：噪声的中性值。该值是噪声的最小值，在节点将输出乘以振幅之后，再加到最终输出结果上。
* **Position**：读取数据时所使用的三维坐标，用于将纹理映射到表面上。默认情况下，使用当前的对象空间 3D 坐标。

## 节点使用说明
**Noise 3D** 着色器节点可通过程序化方式生成 Perlin 噪声图案，你可以用它为材质增加纹理和变化。在应用 **Amplitude** 和 **Pivot** 之前，所有程序生成的噪声值都位于 0 到 1 之间。由于该节点生成的是 3D 噪声，纹理不会在 Z 方向上重复，而是会随着深度变化持续延伸。

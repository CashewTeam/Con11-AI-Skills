本文介绍 Spatial Editor 中的视频组件。
## Video
可以将 2D 或 3D 视频作为视频材质的纹理，映射到创建好的 3D 模型的表面，从而达到在物体表面播放视频的效果。

| **参数** |  | **说明** |
| --- | --- | --- |
| **Mesh** |  | 指定用于显示视频内容的网格。视频画面会渲染到所选网格表面。 |
| **Texture Sample Mode** |  | 指定视频纹理的采样方式。 ;; * **None：**不进行纹理采样，视频纹理将以原始状态显示，不做任何额外处理。; * **Raw：**采用原始纹理采样方式，视频纹理将以最接近原始数据的形式显示，能最大程度保留视频的细节和色彩信息。; * **Blurred：**采用模糊纹理采样方式，视频纹理会经过模糊处理，可用于创建柔和、朦胧的视觉效果。  |
| **Texture Sample Name** |  | 指定纹理采样名称。需要与材质或 Shader 中定义的纹理属性名称对应。 |
| **Display Mode** |  | 指定视频内容的显示方式。 ;; * **None**：视频的显示方式由 **Dimension Mode** 参数决定。 ;  * **Mono**：视频以单视图呈现，无立体效果，适用于普通2D视频或不需要立体展示的视频内容。; * **Stereo**：视频以立体视图呈现，具备立体效果，适用于包含双目视差的3D源视频，如左右并排、上下布局以及MV - HEVC 3D格式的视频。  |
| **Video Material** | **Blending Mode** | 指定视频材质的混合模式。 ;; * **Opaque**：视频材质以不透明方式进行混合。; * **Transparent**：视频材质以透明方式进行混合。  |
|  | **Face Culling** | 指定面剔除方式，例如剔除背面或正面。 ;; * **None**：不进行面剔除，即显示所有面。 ;  * **Front**：剔除正面，即只显示背面，隐藏正面。; * **Back**：剔除背面，即只显示正面，隐藏背面。 |
|  | **Dimension Mode** | 指定视频的维度模式。 ;; * **Mono**：视频以单视图呈现，无立体效果，适用于普通2D 视频或不需要立体展示的视频内容。; * **TopDown**：视频以顶部和底部双视图呈现，通常用于立体视频，上下视图分别对应左右眼画面，为用户提供立体视觉体验。; * **SideBySide**：视频以左右双视图呈现，常用于立体视频，左右视图分别对应左右眼画面，能让用户感受到立体的视觉效果。; * **MultipleView**：视频以多视图的形式呈现，可同时展示多个不同视角的画面，适用于需要多视角观察的复杂视频场景，能为用户提供更丰富的视觉信息。  |
|  | **Color** | 指定视频材质的颜色。可用于对视频画面进行整体颜色调节。 |
|  | **Shader Graph Material** | 指定用于视频渲染的 Shader Graph 材质。设置后，可使用自定义材质效果呈现视频内容。 |
| **Preview** | **Video File** | 指定用于预览的视频文件，用于在 Spatial Editor 中预览视频显示效果。 |

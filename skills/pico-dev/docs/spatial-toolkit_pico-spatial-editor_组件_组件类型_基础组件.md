本文介绍 Spatial Editor 中的基础组件。
基础组件是内置在实体中的，并且无法删除。不同类型实体的基础组件可能不同。
## Static

即 Static Batching（静态批处理）：场景加载后，系统会将所有勾选了 “Static” 的网格（Mesh）进行批处理，并一次性提交至 GPU，从而将 N 个绘制调用（Draw Call）合并为一个或少数几个。
## Transform

用于定义实体在三维空间中的位置、旋转和缩放属性，您可以通过它修改以下参数：
| 属性 | 说明 |
| --- | --- |
| **Position** | 实体在三维坐标系中的空间坐标，通过**X、Y、Z**三个参数精确控制： ;  - **X**：沿水平方向（横轴）的坐标值，正值向右，负值向左； ;  - **Y**：沿垂直方向（纵轴）的坐标值，正值向上，负值向下； ;  - **Z**：沿深度方向（竖轴）的坐标值，正值向前，负值向后。 |
| **Rotation** | 实体绕坐标轴的旋转角度（单位为度），通过**X、Y、Z**三个参数控制旋转方向： ;  - **X**：绕 X 轴旋转（俯仰角），控制实体上下倾斜； ;  - **Y**：绕 Y 轴旋转（偏航角），控制实体左右转向； ;  - **Z**：绕 Z 轴旋转（翻滚角），控制实体沿自身中心旋转。 |
| **Scale** | 实体在三个维度上的缩放比例，通过**X、Y、Z**三个参数控制尺寸： ;  - **X**：沿 X 轴方向的缩放倍数（1 为原始大小，>1 放大，<1 缩小）； ;  - **Y**：沿 Y 轴方向的缩放倍数； ;  - **Z**：沿 Z 轴方向的缩放倍数。 |
## References

用于在当前实体上添加对其他 USD 文件的引用。

* 单击加号按钮即可添加一个新的引用，然后在弹出的对话框中选择需要添加的 USD 文件。

* 单击减号按钮即可删除引用。

## Material Bindings
用于为实体绑定材质。您可以通过它选择当前场景中的材质，并覆盖子实体的材质。

| **参数** | **说明** |
| --- | --- |
| Binding | 从场景中选择一个材质进行绑定。 |
| Strength | 设置材质的绑定强度，用于决定是否覆盖子实体的材质： ;; * **Weaker**：（默认）不覆盖子实体的材质。 ;  * **Stronger**：覆盖所有子实体的材质。 |

一种混合操作，对暗部执行乘法混合，对亮部执行滤色混合。

**Overlay** 节点会根据前景值 `F` 的大小，采用以下两种方式之一进行计算：

* 当 F 小于 0.5 时：`2⋅F⋅B`
* 当 F 大于或等于 0.5 时：`1−(1−F)(1−B)`。这种情况会产生与 **Screen** 节点相同的视觉效果。

## **参数说明**

* **Foreground**：前景输入，在公式中记作 `F`。
* **Background**：背景输入，在公式中记作 `B`。
* **Mix**：混合操作的权重。**Mix** 值越高，混合效果越明显。默认值为 `1`。取值超出 `0` 到 `1` 范围时，会产生超出该节点预期功能之外的未定义效果。

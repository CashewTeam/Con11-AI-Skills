用户可以在特定区域内输入信息。

## 构成

1. **输入区域**
   * 可见的文本输入框，用户可在此输入文字、数字、符号等内容。
   * 宽度通常根据预期输入长度设计（如手机号输入框固定 11 位宽度，用户名输入框自适应内容）。
2. **辅助元素**
   * 图标：如密码框的 “显示 / 隐藏” 图标、清除按钮、输入类型标识。
   * 提示文字：输入框下方的辅助说明（如 “密码需包含大小写字母和数字”）或错误提示（如 “密码输入错误”）。

3. 占位符
   * 输入框为空时显示的提示文字（常用词汇，例如“马上到”），输入开始后自动消失。
      不能替代标签（仅起辅助说明作用）。

   * 带标签的文本输入框一般位于输入框的上方或者左侧，用于描述输入框的用途。

## 交互行为
| **交互** | **说明** | **placeholder** | **value** |
| --- | --- | --- | --- |
| Idle | 未被触碰，边框为基础样式，可能显示占位符，无额外交互反馈。 |  |  |
| Hover | 当通当手势等其他方式扫过文本区域，文本区域进入悬停状态，背景色发生变化。 |  |  |
| Focused | 用户点击输入框后激活，背景颜色改变，光标闪烁提示 “可输入”，且软键盘自动弹出。 |; 提示文案透明度30% |; 光标在 Value 的后面 |
| Typing | 用户正在输入内容，实时响应输入动作。 |; 有 Value 后，后侧有 **清空** 按钮 |; 有Value后，后侧有 **清空** 按钮 |
| Error | 输入内容不符合规则（如手机号位数不足），边框变红，下方显示红色错误提示（如 “请输入 11 位有效手机号”）。 |  |  |
| Disable ;   | 不允许用户操作，输入框及标签灰显（降低饱和度），点击无反应，光标无法进入。 |  |  |
